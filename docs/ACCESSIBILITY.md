# 无障碍选项（ACCESSIBILITY）

Round 41 起游戏提供六项持久化界面设置，主菜单与暂停菜单共用同一组页面，调整即时生效并跨启动保留。本文说明每项选项的作用范围、生效机制与边界，供玩家查阅、供后续轮次（R46 验收、R48 手册）引用。

## 设置总览

| 设置 | 取值 | 生效范围 | 存储字段 |
|---|---|---|---|
| 音量 | 0–10 级 | Phaser 全局声音总线（所有现有与未来音频通道） | `volume` |
| 文字大小 | 小 / 标准 / 大 / 特大 / 最大（0.85–1.6 倍） | 所有面板文本（`uiFontSize` 统一派发） | `textScaleIndex` |
| 移动键位 | 方向键 + WASD / 仅方向键 / 仅 WASD | 探索移动与帮助文本 | `movementLayout` |
| 手柄输入 | 开 / 关 | 标准映射手柄的移动与菜单操作 | `gamepadEnabled` |
| 高对比度 | 开 / 关 | 整张游戏画布 | `highContrast` |
| 减少动态效果 | 开 / 关 | 移动补间、昼夜/天气渐变、NPC 重定位与降水粒子 | `reducedMotion` |

设置存储于 `localStorage` 键 `wuxia-rpg.settings.v1`（与存档槽位键空间隔离）。载荷解析向后兼容 Round 09 的 `{ volume, textScaleIndex }` 旧载荷：缺失的新字段取默认值；任一已知字段存在但无效时整份载荷拒绝并回退默认，且不改动存储。详见 `docs/SAVES.md` 与 `tests/settings.test.ts`。

## 键盘移动布局

- **方向键 + WASD**（默认）：八键全部可用。
- **仅方向键**：W/A/S/D 不再触发移动（避免误触相邻键）；其余功能键（E/F/B 等）不变。
- **仅 WASD**：方向键不再触发移动。
- 布局切换无需重绑：每个移动键的处理函数在按下时读取当前布局（`currentMovementLayout()`），暂停菜单改完的下一个按键立即按新布局工作。HUD 首行与 H 键操作手册的移动说明随布局同步更新。
- 布局只影响**探索移动**；菜单导航（↑/↓ 选择、←/→ 调整）不受布局影响，暂停菜单在两种布局下都同时接受方向键与 W/S。

## 手柄输入（标准映射）

手柄支持遵循浏览器 [标准 Gamepad 映射](https://docs.phaser.io/api-documentation/class/input-gamepad-gamepad)（Phaser `Gamepad` 类，来源登记于 `docs/REFERENCES.md` #17/#18）：

| 输入 | 作用（探索中） | 作用（菜单/暂停中） |
|---|---|---|
| D-pad / 左摇杆 | 单步网格移动 | 上下移动选中行，左右调整设置 |
| A（底部按钮） | 交互（等同 E） | 确认（等同 Enter） |
| B（右侧按钮） | 暂停菜单（等同 Esc） | 返回上一页（等同 Esc） |

设计与边界：

- **按住不连发**：摇杆/按键状态经边沿检测（`src/game/input-settings.ts` 的 `GamepadEdgeTracker`）转换为"按下沿"——持续按住只触发一次，摇杆从一个方向转到另一个方向计为新一次按下。单元测试覆盖（`tests/input-settings.test.ts`）。
- **死区与基数优先**：左摇杆向量的合成偏移幅度（`hypot(x, y)`）低于 0.5 视为居中；斜向偏转取分量更大的轴（完全对角时取水平轴），网格行走不出现斜向输入。D-pad 按下时优先于摇杆。
- **总开关**：所有手柄动作都以 `gamepadEnabled` 设置为门。关闭后轮询早退，控制器不触发任何动作；无控制器设备时同样早退，键盘行为完全不受影响。
- **设备发现限制（浏览器行为）**：多数浏览器要求玩家先按一次手柄按钮才向页面开放设备（`gamepadconnected`），且部分浏览器要求 HTTPS 环境。因此"插着手柄但没反应"时请先按任意手柄键。
- **物理硬件验证边界**：Round 41 的自动化验证覆盖方向解析、死区、边沿与菜单路由逻辑（单元测试）；未在真实控制器硬件上做人工测试，`DEVLOG.md` 如实记录。

## 高对比度

- 机制：开启时对**整张游戏画布**应用 CSS 滤镜 `contrast(1.4) saturate(1.25)`（`HIGH_CONTRAST_FILTER`，`applyGameSettings` 写入 `game.canvas.style.filter`）。
- 即时性：主菜单/暂停菜单切换当帧生效；下次启动时启动路径自动恢复。
- **边界（重要）**：这是对现有像素画面的整体显示级增强，作用于画布内全部内容（场景、HUD、面板）。它**不等同于**符合 WCAG 的逐元素色彩审计——未做对比度比值的逐对计算与认证。R46/R48 验收若需 WCAG 合规结论，须另行逐元素审计。

## 减少动态效果

开启后以下呈现改为无补间方式，**游戏状态推进与回调完全保留**：

| 呈现 | 常规 | 减少动态 |
|---|---|---|
| 玩家移动 | 110 ms 位移补间 | 瞬移到目标格，同帧完成（伙伴跟随、区域事件、热重载边界照常触发） |
| 昼夜照度切换 | 600 ms 交叉淡入 | 直接设置目标透明度 |
| 天气色调切换 | 600 ms 淡入 | 直接设置目标透明度（色调本身保留） |
| NPC 日程重定位 | 420 ms 位移补间 | 直接定位 |
| 雨/雪降水粒子 | 持续飘落粒子 | 不生成；开启设置时立即销毁既有粒子 |

- 设置切换时立即销毁现存降水粒子、停止当前昼夜/天气补间并设置目标透明度；关闭减少动态后按当前天气恢复降水表现，无需等到下一日更新。
- 帮助文本"移动与昼夜/天气变化不播动画"如实描述此范围。
- 战斗与面板 UI 本无补间动画（逐帧重绘），不受该设置影响。
- 伙伴跟随（`refreshCompanionFollower`）原本即为直接定位（无补间），本设置下行为一致。

## 文字大小

- 五档倍率（0.85/1/1.2/1.4/1.6），索引 1（标准）为默认。R41 新增 1.6"最大"档：960×540 画布与各面板布局按该档校验过行距（设置页 6 行在暂停面板内不与反馈行/提示行重叠）。
- 生效机制：所有 UI 文本经 `uiFontSize(base)` 派发像素字号；探索 HUD 的既有文本通过 `refreshScaledTextTargets()` 在设置面板关闭时刷新。面板重渲染（打开/翻页/调整设置）自然采用新字号。
- **边界**：画布内文本（Phaser Text）即时缩放；页面外壳（`index.html` 标题等 HTML 文本）不在画布内，不受该设置影响（外壳目前仅有 `document.title`，无可见正文）。

## 与既有输入锁的关系

无障碍输入与既有"面板打开时探索输入锁定"（`anyOverlayOpen()`）正交：手柄轮询在探索态走移动/交互，暂停菜单打开时改走菜单路由；对话、战斗、背包等面板打开时手柄方向不触发移动（与键盘一致）。
