# 结局资料与判定（Round 27）

结局是可选的世界资料，由 ending-set Schema 校验；引擎只解释统一条件协议、验证终章地图入口并呈现玩家结局。世界没有有效 ending.round-27-set 资源时，其余区域、任务和成长系统照常加载。

## 文件与覆盖

- data/schema/ending-set.schema.json 定义封闭字段与数值边界。
- data/base/endings/round-27-endings.json 声明入口、五条基础归宿和两条 Round 42 主线结局。
- data/base/manifest.json 登记资源 id ending.round-27-set。MOD 可用相同相对路径 endings/round-27-endings.json 覆盖。
- 每条结局用 knowledgeNodeId 指向图谱中的 kind 为 ending 的节点；图谱边用于百科和关系探索。

gate 包含稳定 id、名称、地图 id、格坐标和相邻交互提示。世界装配验证地图/坐标可用，并拒绝出生点、NPC、遭遇、门派战、锻造/炼丹工位、关口或区域事件占用的格子；入口格同时从所有 NPC 时段日程中留空。坏入口关闭结局入口并报告 warning，不阻止世界启动。

## 结局与条件

结局字段为 id、knowledgeNodeId、title、epilogue、priority 和 conditions。每条结局需要 1–12 个条件，**全部满足**才可达；条件按 priority 降序显示，同优先级再按 id 稳定排序。条件带资料作者书写的 hint，锁定时可解释还差什么。

| 条件 kind | 字段 | 判定 |
|---|---|---|
| questStatus | questId、status | 任务状态严格相同 |
| morality | minValue 和/或 maxValue | 善恶闭区间（−100…100） |
| renown | minValue 和/或 maxValue | 江湖声望闭区间（0…1000） |
| npcRelationship | npcId、区间 | 指定人物关系闭区间（−100…100） |
| factionMembership | isMember、可选 factionId | 是否属于指定门派；省略 id 时检查是否在任何门派 |
| factionRenown | factionId、区间 | 指定门派声望闭区间（0…1000） |
| knowledgeKnown | nodeId | 玩家已发现该知识节点 |

解析器先做防御性字段检查，跨资源装配再核对任务、人物、门派、知识节点与结局节点；单条引用失败只禁用该结局。当前状态由纯函数只读评估；确认时重新判定，锁定结局不可被伪造 id 绕过。判定不改变角色、任务、物品或社会值。

Round 33 起，每条结局中引用图谱节点的可判定条件（任务状态、已知见闻、门派在籍、NPC 关系）都在知识图谱中有从条件来源指向该结局节点的 `influences` 边（如「巷口除患 → 铁嶂砺心」「陆贞娘 → 河灯归处」）；善恶、江湖声望、门派声望等纯数值条件没有图谱来源，不设边。玩家可在百科结局词条下追溯这些来源；`npm run smoke:round-33` 逐条件核验影响边存在。

## 基础路线

- **河灯归处**：完成「巷口送药」，善恶达到 5，与陆贞娘关系达到 10，并发现雨后脚印。送药交付会带来个人声望；达到声望门槛后可在茶棚增进关系。
- **听雨守约**：完成「巷口除患」，拜入听雨剑阁，剑阁声望达到 10、叶庭舟关系达到 5、江湖声望达到 5。
- **铁嶂砺心**：完成「巷口除患」、拜入铁嶂派、铁嶂声望达到 10、石北关系不为负、江湖声望达到 5。
- **云隐护生**：完成「巷口送药」、加入云隐山庄、云隐声望达到 10、与闻素心保持中立、善恶达到 5。
- **行舟万里**：发现雨后脚印，且保持无门无派。它为已经走到渡口、仍想自行择路的玩家保留开放归宿。

### Round 42 · 水痕主线结局

- **公簿昭潮**：完成「旧簿验痕 → 两家对页 → 封存水痕」，在白鹭洲处选择「明册立约」，再与柳听澜交谈将证物列入副册。结局条件为 `quest.r42-open-register = completed` 和 `event.r42-public-record-vow` 已知；公开记录与复核空间一起保留，不把水痕本身当成定罪。
- **灯下留痕**：完成共同章节，在白鹭洲处选择「护证留印」，再与祝九弦交谈收存证词与拓本。结局条件为 `quest.r42-protect-witness = completed` 和 `event.r42-protected-witness-vow` 已知；证人暂不公开，证据仍留待各方对页。

两条路线共用「封存水痕」前置，互斥组 `branch.r42-ferry-record` 保证一档只能选择其一；任务名录和对白选项共用同一接取状态。完成对应谈话目标后，目标人物会给出该路线专属回应并记录见闻，因此不论从对白还是任务名录接取，结局判定都走同一数据条件。Round 42 不引入真凶判定，也不替未知的未查明部分补写定论。

数值门槛按当前基础对白和门派入门规则设置为可达到。关系取值、任务结果、门派声望和善恶在游戏内已有对应路径，不以不可达阈值伪装“隐藏结局”。

## 游戏操作与存档边界

走到“照心石”四向相邻格后按 E。方向键/WASD 浏览结局，Enter 确认可达选项；锁定选项显示其资料提示。选择后呈现终章正文，再按 Enter 或 Esc 返回主菜单；在尚未选择时 Esc 可离开推演回到地图。结局面板期间探索输入锁定。

结局选择会结束当前旅程，不覆盖任一存档槽，也不保存终章选择记录。想尝试其他路线，可从到达终章前手动保存的槽位读档。成就册/跨新档结局历史不属于本轮。

## 校验与烟测

- npm run validate:data 校验 manifest 和所有登记资源 Schema。
- npm run smoke:round-27 验证全部条件族、闭区间阈值、基础路线、锁定提示、只读判定、MOD 悬空引用隔离、入口几何/邻接、完整世界加载和 NPC 日程让位。
- npm run smoke:round-33 验证结局节点映射、结局节点默认未知，以及全部图谱可判定条件来源的影响边闭环。
- npm run smoke:round-42 验证 R31 后续章节解锁、两种互斥选择、对白图跨资源引用与两条新结局的可达状态。
