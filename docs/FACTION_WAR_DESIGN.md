# 门派战与会盟

Round 21 新增一场原创的渡口门派战，用来验证多人阵营对抗、贡献结算、世界声望后果和图谱/对白联动。它复用回合战斗与社会状态规则，不把战事敌手登记成普通地图遭遇。

## 资料组织

资源 `faction-war.round-21-set` 由 `data/schema/faction-war-set.schema.json` 校验，默认文件为 `data/base/faction_wars/round-21-wars.json`。每项战事声明入口、两支参战门派、贡献门槛、阶段和胜/平/负结局。每个阶段分别声明两派弟子的对手属性与武学，因此报名弟子始终迎战对方门派；阶段标题、贡献、经验、败阵恢复、对话文本都由 JSON 配置。

世界装配再对照地图格、出生点、NPC、遭遇、擂台、两派 id、双方对手武学和每个结局的知识节点。无效入口/引用只禁用对应战事并生成 warning；缺少该可选资源时其余世界照常启动。日程编译也会把有效入口当成固定占位，避免时段迁移的 NPC 站到交互格上。

## 报名与结算

玩家在入口邻格或入口格按 E 打开会盟面板。只有当前身份属于参战两派之一的弟子可以报名；页面列出双方各阶段对手、胜利贡献、贡献门槛和本地战绩。最多 12 个阶段按当前面板高度分页，使用 PgUp/PgDn 浏览，不会挤占战绩与操作区；仅查看不会新建空白战绩记录。Enter 开始后阶段顺序使用通用 `CombatSession`，伙伴援护、胜利经验、败阵恢复和撤退规则保持一致。

- 阶段胜利增加该阶段贡献；阶段败阵后按该阶段恢复比例调息，可继续参加后续阶段。
- 达到贡献门槛即以胜方身份结束；所有阶段结束时，已有贡献但不足门槛为平局，贡献为零为败局。
- 主动撤退提前结算，沿用当时贡献分档。门槛达成时已在胜利结算处立即结束，不会再多开阶段。
- 结算以玩家所属门派为“己方”，按该战事 JSON 中的胜/平/负后果调整个人声望、己方门派声望和对方门派声望；既有 social-state 统一钳制到协议范围。
- 每种结局解锁对应图谱事件节点。石北与闻素心的导师对白都以 `knowledgeKnown` 条件呈现对应战报，百科可查看事件说明。

## 存档和 MOD

v1 快照的 `factionWarRecords` 按战事 id 记录报名次数、胜/平/负次数、历史最高贡献、最近贡献及最近结果。Round 20 及更早存档缺字段时默认为空数组；读档遇到已被 MOD 移除的战事记录会过滤该条并提供 warning，不会拒绝其他进度。用同 manifest 资源 id 和路径的 MOD 文件即可替换默认战事内容。

## 验证

`npm run smoke:round-21` 在无 Phaser 运行时验证战事解析与跨资源装配、坏入口/坏阵营引用隔离、双方对手选择、六种（两派 × 三阶段）通用战斗会话、贡献结局分档及新旧 v1 战绩存档往返。全量 `npm run validate:data` 另验证 manifest 和所有登记资源的 JSON Schema。
