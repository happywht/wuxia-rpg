## 浏览器手动纵向流程

环境：本地 Vite 开发服务器 `http://127.0.0.1:5178/`，首次试玩时槽一、槽二均显示“空（新建存档）”；全程使用界面键盘操作。

1. 主菜单按 Enter 开始新游戏，默认“抄书学徒”进入方格试炼场 `(7,7)`；按方向键走格，墙格不能通过。
2. 沿第七行向西至 `(2,7)`，按 E 触发“巷中刀客”；选择普通攻击五回合，画面显示敌方生命降至 0、玩家存活并获得经验/升级。
3. 回到街巷，绕过墙体到陆贞娘邻格，按 F 对话；选择打听生面孔并追问背刀客，获得“雨后的脚印”见闻。按 Q 查看差事，接受“帮口送药”，背包已有两份回春膏，显示 `2/3`。
4. 到叶庭舟处先请教剑意提高关系，再加入听雨剑阁。导师剑法被角色属性门槛隐藏；返回探索后按 C，组合招式、架势和吐纳，输入“归潮听息”并确认。面板显示“已创 1/5 门（归潮听息）”。
5. 等到日中，穿过北街到姜百味邻格，按 E 打开商店并买一份回春膏；按 B 验证数量从 2 增至 3。Q 面板显示“帮口送药”`3/3`、已完成，奖励经验 15、银两 13。
6. 暂停菜单进入“保存进度”，先确认空槽一后保存；取得第三份回春膏后再保存到原先空的槽二。刷新后从 Continue 读槽二，地图恢复至 `(8,1)`，B 显示回春膏 `×3`，C 显示已创武学 `1/5` 且名称仍在。

修复前读入由旧逻辑写下的槽二时，控制台出现“跟踪中的任务不是进行中任务”警告：收集任务已因取得第三份物品自动完成，但旧存档仍保留其跟踪 ID。Round 50 修复 `completeQuest` 在完成时同步清除跟踪 ID，并添加任务完成/收集物即时完成回归。修复后用读入后的已归一化运行状态保存到空槽三，刷新并 Continue 读入槽三；地图再次恢复至 `(8,1)`，没有新增同类跟踪警告。会话日志里仍留有四条来自修复前两次旧槽读档的历史警告，不将其表述为控制台零警告。

本轮未执行真实远端 CI 或 GitHub Pages 发布：仓库没有配置 Git remote。也未进行物理手柄硬件或外部公测验证；这些不属于目标文件要求的本地最小玩法闭环。
