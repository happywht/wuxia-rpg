## 资料作者说明

- 新物品在上述 `items` 数组追加，使用稳定的 `item.` ID；不得复用历史 ID。消耗品至少一项恢复值大于零；装备只使用现有三个槽位和五项通用属性。
- `buyPrice: 0` 表示物品不以买入价出售；是否上架只由 shop-set 的 `stock` 决定。有限库存耗尽后不会自动补货。
- 新物品必须有可追溯的获得方式：商店货架、锻造结果、炼丹结果、任务/对白奖励之一。Round 32 的八件新消耗品、两件基础装备和九种材料已上架；六件进阶装备由铁砧配方生成。
- 扩展前先运行 `npm run validate:data`，再执行 `npm run smoke:round-32` 检查物品总量与商店/配方引用。
