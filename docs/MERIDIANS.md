# 经脉与内修（Round 23）

经脉是可选的数据族，不是角色成长引擎的专属世界设定。基础资料位于 `data/base/meridians/round-23-meridians.json`，通过 manifest 的 `meridian-set` Schema 登记；MOD 可以用同一路径整文件覆盖。资源缺失或结构/语义校验失败时，世界与普通战斗照常运行，只关闭 N 键入口。

## 资料协议

根对象含 `resource` 与 `nodes`。`resource` 指定 `initialPoints`、`pointsPerLevel`、`maximumPoints`。节点含稳定 `meridian.*` id、名称、说明、`minimumLevel`、`pointCost`、前置节点、材料成本和效果。每节点效果可添加五项基础属性、气血上限及内力上限；前置关系须引用存在的节点且无环。节点最多 64 个，材料最多 8 种，单项数量不高于 99。

装配阶段会跨资源检查材料 id。引用不存在的材料会禁用该节点和依赖它的节点并报告 warning，其他经脉可用。运行时同样会防御检查材料仍存在、数量足够、未装备、修为足够、等级与前置条件满足。

## 运行规则

- 新角色从当前经脉资料获得初始修为；战斗胜利或任务经验结算后，仅按实际升级数发放 `pointsPerLevel`，并受存储上限约束。
- N 打开经脉页，方向键/W/S 选择节点，Enter 打通，Esc/N 关闭。打通时先核验全部条件，再扣修为和材料并记录节点 id；失败不改变角色、背包或修为。
- 打通效果立即合并到有效属性和气血/内力上限。该效果单独保存为派生来源，不写入基础属性，因此装备调整和升级不会重复叠加或覆盖。
- 战斗的力量、体魄、定力、气血与内力直接读取经脉加成后的角色状态；普通遭遇、擂台和门派战共用同一结算。

## 存档与 MOD

v1 快照保存未用 `cultivationPoints` 与最多 64 个唯一 `unlockedMeridianNodeIds`。旧 v1 档缺字段按 0 点和空节点兼容。读档时根据当前启用节点集合过滤 MOD 已删除的节点并给出 warning；加成完全由当前资料重新汇总。修为/节点被编辑为非法类型、越界或重复 id 时拒绝整份损坏快照。

验证入口：`npm run validate:data` 与 `npm run smoke:round-23`。烟雾脚本覆盖前置 DAG、悬空材料隔离、升级修为、事务拒绝不变性、角色效果重算、战斗升级与新旧存档兼容。
