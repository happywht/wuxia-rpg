### PT-49-01：默认资料告警且锻造配方被禁用

- **严重度**：P2（开局 HUD 报告可选资料无效；受影响的是一条锻造配方）。
- **复现**：主菜单 → 开始新游戏 → 进入方格试炼场；HUD 显示“部分可选资料无效”。以仓库真实 `data/` 运行 `loadWorldData()` 后，可定位到 `forge.recipe.r32-marsh-amber-seal`。
- **原因**：配方产物“沼琥珀印”是“蚌光佩”的升级，但属性配置将原有 `resolve +2 / qi +15` 换成了 `insight +2 / health +12 / qi +14`，违反同槽升级不得降低任一基础加成的校验。
- **修复**：保留 `resolve +2`，增加 `insight +2 / health +12`，并将 `qi` 提至 `+16`。配方现可装配，开局 HUD 不再提示默认可选资料被禁用。
- **验证**：`tests/round49-default-world-integrity.test.ts` 从仓库真实资料装载所有 manifest 资源，并断言核心内容数量及可选装配告警为空；重新进入浏览器新游戏时警告行消失。
- **状态**：已修复。

### PT-49-02：暂停子页 Esc 同时关闭整个暂停层

- **严重度**：P2（设置/保存页的返回行为与页脚提示不符）。
- **复现**：探索中按 Esc 打开暂停 → 进入“设置” → 按 Esc。修复前页面直接回到地图，没有先回到暂停菜单；根因是暂停面板和地图场景同时接收同一次 Escape。
- **修复**：暂停菜单打开时，由面板独占该按键；场景级暂停切换处理器不再关闭已打开的暂停面板。
- **验证**：浏览器手测设置页 Esc → 暂停主页，暂停主页 Esc → 探索；保存页显示三个空槽，Esc → 暂停主页。没有执行保存，未覆盖存档。
- **状态**：已修复。
