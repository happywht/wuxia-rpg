# 五阶段产品打磨执行方案

2026-10-04 / Round270。严格按1→2→3→4→5推进，QA基础设施、矩阵、必要模块抽离服务当前阶段。以下稳定资料ID对应的**改造合同是验收承诺，不能读作已经实现**。

## 1. 江南—渡口—云岭代表旅程

目标首玩60–90分钟，设计预算75分钟。主动操作、阅读/选择、迷路、补给、失败/读档分别记录；工具延迟和后台等待不计体验时长，世界分钟不换算人类时长。预算与实测冲突时改善密度，不强迫等待凑时长。

| 段/预算 | 为何出发 | 途中变化与玩法 | 到达回报 | 回程政策 / 检查点 |
| --- | --- | --- | --- | --- |
| J0 街巷求生 / 10分 | 伤者缺药、刀客堵巷 | 茶棚、姜百味采购/采草、巷口战斗、实际用药；Q说明花费和目标 | 首差事、等级成长，知道渡口药庐为何值得去 | 镇内道路可辨，不要求清完开局任务。`j0-opening` |
| J1 师承 / 8分 | 战斗暴露短板，寻师获得新能力 | 资格可读、拜师、学一种有用途的武学，未入门也能继续 | 武学/身份可见，导师给药庐/山路方向 | 缺料出镇前明确预告，不能到渡口后盲返。`j1-departure` |

## 2. 固定12项既有差事改造合同

每项至少两种解决同一困难的行动，区别涉及资源、步骤、风险或可见机制，覆盖战斗/药物/关系/调查。不能把邻近两任务算成一个任务的多解。用对白/知识/变量和必要的通用目标备选协议，引擎不得按任务ID特判。

| # / 稳定ID | 同一困难的两种行动 | 不同代价和后果（拟实现） | 验证重点 |
| --- | --- | --- | --- |
| 1 `quest.r31-teastall-herbal-water` | 采草配凉汤 / 药理调查替方 | 时间环境 vs 替方材料/悟性；茶棚供给或信任 | 实扣料，不重复结算 |
| 2 `quest.round-07-medicine-run` | 购药送伤者 / 自制替伤药 | 银两 vs 配方/工钱；人物识别药物和后续帮助 | 实交付消耗，兼容旧进行态 |
| 3 `quest.round-07-clear-alley` | 战斗击退 / 查证劝离 | 生命内力 vs 证据/谈判；退出占位、不同口碑 | 非战斗不伪造胜利，读回占位 |
| 4 `quest.r31-herbal-inquiry` | 当面问诊 / 查药案复核 | 往返关系 vs 调查步骤；不同治疗建议 | 寒暄不代专用复核，无无限奖 |
| 5 `quest.r31-herbal-stocktaking` | 生肌散 / 合格双补药实践 | 配方药材工钱/恢复量不同，后续准备不同 | 都须真实制作和有收益使用 |
| 6 `quest.r31-mist-shore-watch` | 战斗捕探子 / 追迹布防逼退 | 战败用药 vs 时间调查关系；后续伏兵准备不同 | 后续威胁行为有实际变化 |
| 7 `quest.r31-caravan-provisioning` | 无极丹封箱 / 药案等效补给 | 25银购丹 vs 复杂药料制作；队伍补给/信用 | 显式约时、原子扣料 |
| 8 `quest.r31-guard-the-caravan` | 正面护队 / 侦察借地形护队 | 战损 vs 布防料/行动；不同补给承诺/信用 | 都真正护队，有失败边界 |
| 9 `quest.r31-mend-the-pier` | 足料补桩 / 勘桩借关系调配 | 铁砂3/韧皮2 vs 调查信用/替料；桥通行/收费 | 不仅计持有，幂等存读 |
| 10 `quest.r31-blade-quench-stock` | 淬锋实战 / 合格防具防御实践 | 武器砂工钱 vs 防具料/战法，对应不同挑战 | 锻造/装备/运用都真实 |
| 11 `quest.r74-cloud-marks` | 现场辨刻 / 导师笔记对照 | 调查路径 vs 门派实践关系；线索/信任不同 | 不由纸龄断刻龄，结论边界 |
| 12 `quest.r74-cloud-bridge` | 清桥战斗 / 药物或查证调停 | 战损 vs 药/证据关系；通行、当地补给回响 | 占位真变，清敌不冒充修索 |

阶段1落实全段必需项；阶段2逐项完成完整合同。无法验证区别时调整设计，保持原12任务ID，不虚增数量。每项矩阵含实现文件、自动证据、QA-A/B、存读后果；12/12成立才进入阶段3。北境/海路按同标准随后推广，历史结果不冒充新候选验收。

## 3. 成长、敌人与制作

- 守御反击：预读重招→付回合/气守御→有效抵御后反击，明确持续、触发、窗口和伤害记录。不能只增加防御数值。
- 轻身耗敌：预读冲刺/蓄力→付气轻身→避关键伤害→小招耗敌；禁止无限无代价闪避。状态/冷却按此挑战需要补齐。
- 相同等级/属性预算、同一敌人分别通关，逐回合记意图/动作/气/药/时间/败因，不拿不同等级比较伤害。
- 药物与淬锋/防具各成真实地区用途循环，材料/工钱/品质/恢复或抗性/替代方案可读；五派按同挑战需要复核地区实践。
- 意图和执行共享求值，无气替代也提前可读。扩展字段缺省兼容旧v1/MOD，熟练度仅在路线确有必要时接线。

## 4. UI与合法像素素材

- Q当前/最近结案突出；预计与到账分明，读档无收据诚实显示约定报酬；长标题、分页身份、最大字号、窄窗口实用检查。
- E按提示物/关口/商店，F人物；Q/N、R、M共用真实导航几何；返回/分页一致，说明与执行一致。
- 合法图集先统一色板/明度/材质，三种入口、可行道路、交互物有统一视觉；人物与背景对比，屋顶/树冠前后遮挡可辨。生成源同步、REFERENCES可追溯。
- 六代表区入口→枢纽、补给→挑战、目标→回報实走前后对照，记录迷路遮挡；静态BFS不代体验。
