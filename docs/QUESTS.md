## 协议速览

- **目标四型**：`collectItem`（按当前持有量推进，接取时快照）、`defeatEncounter`（对应遭遇胜利一次记一功）、`talkToNpc`（玩家实际打开目标人物对话一次记一功）、`discoverKnowledge`（首次发现指定图谱节点时推进一次，`requiredCount` 必须为 1）。已知目标见闻会在接取时回填；兼容旧存档恢复后也会按已知见闻对活动目标重算。谈话信号只由场景的 `openDialogueWith` 发出：**F 键交谈**与**对无名录/无商店 NPC 的 E 键交谈回落**都算谈话；**E 键打开任务告示板不算**，接取差事的同一次交互也不会自动完成谈话目标。
- **互斥分支**：声明相同 `exclusiveGroupId` 且前置完全一致的任务构成一次玩家选择，装配时整组校验（有效成员 ≥ 2）；本轮药道组选项同列在白鹭洲的告示板，接取其一，其余已解锁成员立即记为失败（`failed`），各自后续只由对应选择解锁。
- **失败条件**：`failOnEncounterIds` 声明的遭遇一旦战败，该差事立即失败；放弃进行中的差事同样记为终态。
- **门派/见闻资格**：可选 `requiredFactionId` 与 `requiredKnowledgeNodeId` 同时成立才可接取。任务名录隐藏不符合资格的 offered 差事；接取 API 与对白效果事务再次权威校验。资格只在接取时检查，已接任务离门后仍可完成。
- **一次性后果奖励（Round 44）**：`rewards.factionRenown` 与 `rewards.discoverKnowledgeNodeIds` 跟经验/银两一起只在首次完成状态转移时发放；门派引用和见闻引用在装配期校验，声望受统一 0–1000 边界钳制。
- **状态与存档**：全部复用 `locked/offered/active/completed/failed` 五态与按目标 id 存储的 v1 快照，无新存档字段。
- 本页总表、分支路线与遭遇表由 `npm run audit:round-34` 对照 `data/base/quests/round-07-quests.json`、`data/base/battles/round-05-encounters.json` 与 `data/schema/quest-set.schema.json` 核验：任务名、发布人、前置、目标 kind、失败遭遇、基础报酬及声望/见闻报酬任一漂移都会使审计非零退出。

## 章节叙事

### 第一章 · 巷陌与口信（江南道·七镇行旅）

巷口的刀客惊扰镇西之后，马尚义继续张罗伤者的药与疮口（巷口送药 → 灯下问药）；茶棚、书铺各有一桩随手可做的小事（茶棚凉汤、书铺驱蠹）；姜百味的货担要回程，一句改走水路的口信须当面带到（货郎口信）；顾夜尘看出你招式缺狠劲，一页荐帖把线牵到渡口刀场（路旁荐帖）。四条线彼此独立，开局面板即可接取。

### 第二章 · 药庐与渡籍（雾雨渡口）

容素青的药案串起问药与备药（灯下问药 → 药庐清点）；白鹭洲的渡籍被雨泡坏，寒山书院的教习柳听澜誊正用印，学生们熬夜抄档又熬垮了精神（渡籍补录 → 书院夜课）。河灯之约则从茶棚的旧约出发，落在渡口的水面上。

### 第三章 · 药道抉择（互斥分支）

闻素心先要巡清北岸的探子（雾夜巡岸），石北才肯发药队启程的最后一步（药队启程）。此后雾渡药道走到岔口：渡董白鹭洲把两条差事同时挂上告示板，转述石北主张**先保药队**硬闯芦苇水路，也列出自己主张的**先修栈桥**方案，让玩家在同一处比较选择；接下一条，另一条就此封止。A 线的后续是云隐山庄挨家挨户的当面致谢（药队答谢）；B 线的后续是清扫桥头自称管事的索银人（栈桥通渡）。

### 第四章 · 耳目与勘验（收束）

顾夜尘要摸清药道往后安不安生，分别去问刀场与书铺的口风（江湖耳目）；祝九弦收帖后按刀场规矩让你自备淬料（刀场淬料）；药队启程之后，叶庭舟布置师门勘验——拳脚之外，还要认得人、认得药（师门勘验）。

### 第五章 · 水痕与对页（原创主线，Round 42）

「渡籍补录」完成后，白鹭洲请玩家把正本与书院副本对页（旧簿验痕）。柳听澜看出誊副前已有异样，但不肯凭纸痕推断人名，于是请玩家分别询问熟潮时的顾夜尘与认旧船印的祝九弦（两家对页）。两份口述指向同一张旧压纸，顾夜尘让玩家拓下一份不可买卖的「渡籍水痕拓本」（封存水痕）。证物留存后，玩家在白鹭洲处决定把副册公开交柳听澜立档，或先由祝九弦保护证人与拓本；两条互斥路线分别落在「公簿昭潮」与「灯下留痕」。叙事只确认有水痕、潮时与旧印的疑点，不预设真凶，也不把尚未对证的猜想当作定案。

### 第六章 · 风雨传函与五派核验（原创支线，Round 43）

在雾雨渡口完成旧脚印见闻后，玩家于黄昏至夜间的湿天气行走，有机会遇到持五封匿名求助信的赶路人。传函分别把剑鸣、石桩空响、封蜡药香、渡籍缺页和缆痕交给五派判断；信中只列观察，不点名嫌疑人。各门派弟子凭已发现的传函见闻向本门导师接取一项核验差事，再与对应知情者交谈。路线结论分别指向索环回弹、石桩空槽、陈艾苦香、旧抄缺页和运盐船缆痕，并作为后续百科见闻保存。

### 第七章 · 雾岬巡标与南湾测绘（原创探索支线，Round 56）

玩家先在旧渠石闸读到潮尺铭文，才可从石北的名录接取「雾岬水尺巡查」。走至 `(86,15)` 的雾岬北岸石桩后，发现的地点见闻同步完成任务并开放后续「南湾水路测绘」；走至 `(81,87)` 的苇根旧水标，第二段再以一次新发现收束。两个发现格都标在 100×100 渡口地图上，已知目标会在接取时补齐，避免重跑已探索路线。

### 第八章 · 芦桥开市与南麓茶道（区域支线，Round 58）

石北从已查明的南湾浅槽与旧渠残船号引出「芦桥寻集」；玩家走到芦桥集 (59,65) 读出旧幌，见闻会同时完成第一段并解锁白鹭洲的「集期赶办」。备好三条韧皮料、再与石北当面划定摊棚与药担通路后，祝九弦托玩家到集口赶走假借旧例索钱的管事（「集口拦贩」）。敌人位于渡口 (60,67)，设为可重战，早先胜过也不会锁死任务；进行中战败仍按任务规则失败。

江南道一线接在「巷口送药」之后：马尚义托玩家沿南坡茶匾找到聚落旧驿道（「南麓寻村」，见闻发生在南麓聚落 (70,75)）；陆贞娘随后请你备两份无限补货的苍崖根，并通过 F 键与姜百味交谈，让货担按查明的旧路捎药（「南麓捎药」）。最后顾夜尘报告东野池塘有人假冒护队，玩家前往可达的东野边路 (80,20) 击退冒牌护药队（「塘匪断道」）。新任务复用现有人物、商店物资与区域资源；常显城镇地标不加见闻门控，因此旧存档不会丢失原有目的地。

Round 59 为六项任务的发布人与谈话目标补入对话回声：石北、白鹭洲、祝九弦、马尚义、陆贞娘、姜百味、顾夜尘七人的既有对话各增加活动中/完成后两组仅按 `questStatus` 显隐的回应选项（无 effects，不重复接取或结算）；石北与姜百味作为谈话目标，谈话信号先于首节点选项求值，带齐材料的玩家当次对话即见完成态回应（`tests/round59-regional-dialogue.test.ts`）。

### 第九章 · 雾岬北隘与烽台更次（原创区域链，Round 62）

雾岬北岸水尺被记录后，玩家可从铁嶂北道·岩关驿镇的邵长庚处接「北隘校标」，到碎岭旧道 `(30,29)` 发现界石凿痕并解锁「驿镇更次」。第二段要求找秦素砚 `(57,49)` 核对北脊旧烽台巡山更次；第三段「碎岭清道」要求击退可重战的拦路客 `(71,63)`，结算经验、银两和铁嶂派声望。另一场可重战遭遇「烽台盗石人」位于 `(87,80)`，补充探索冲突但不锁住主任务。邵长庚与秦素砚的基础位及七时段路线由 Round 62 专项测试复核；详细地区与事件数据见 [`MAP-ATLAS.md`](MAP-ATLAS.md) 和 [`CHARACTERS.md`](CHARACTERS.md)。

### 第四区域：西陲盐道·青岩驿（Round 67）

罗金子在青岩驿 `(48,49)` 接待往来盐道的旅人；晨光时移到账桌，入夜后移至后院。玩家接取「苦井辨线」后前往回声苦井 `(26,28)`，通过一次性区域事件读出水线见闻 `place.r67-brine-well`，见闻目标即完成差事并结算 24 经验、17 银两。目标事件与舆图地标共用同一发现节点，所以在接任务前已经查过苦井的旧存档，也会按既有任务规则回填完成；相应地标只在玩家知道该节点后显示。青岩东关连接铁嶂北道，白石晒盐坪 `(76,25)` 提供额外的区域导航地标；盐道另有可重战遭遇，但不是本任务必要目标。

### 第五区域：云岭古道·断云栈道（Round 74）

沈雨霁在云栈客舍 `(39,43)` 记录山道走向，晨光时移至 `(38,42)`、黄昏移至 `(41,44)`。从铁嶂北道断云北隘抵达 `(50,97)` 后，玩家可发现区域入口见闻，再与沈雨霁交谈接取「云阶辨刻」；到云纹石阶 `(27,31)` 调查一次性事件，发现 `place.r74-cloud-markers` 后完成第一段并解锁「断索清桥」。第二段可在同一 NPC 处接取，前往断索悬桥 `(75,42)`，击退可重战拦路客后结算 44 经验、32 银两。发现石阶/悬桥的舆图标记均受对应见闻门控；已发现石阶的旧档由既有任务系统规则回填目标。
