# 任务志（QUESTS）

- 状态：Round 42 起基础世界共有 **25 项原创差事**，横跨方格试炼场与雾雨渡口，包含两组真实互斥分支（先保药队 / 先修栈桥；明册立约 / 护证留印）、三条战败即失败的护送与巡岸线，以及收集、谈话两类非战斗目标；资料在 `data/base/quests/round-07-quests.json`（`quest-set` schema），任务专用遭遇在 `data/base/battles/round-05-encounters.json`。
- 关联：`docs/CHARACTERS.md`（12 名发布人物）、`docs/FACTION_WAR_DESIGN.md`（雾渡药道会盟背景）、`docs/ENDINGS.md`（七条结局的任务/见闻条件）、`docs/DATA-GUIDE.md`（任务协议字段）。

## 协议速览

- **目标三型**：`collectItem`（按当前持有量推进，接取时快照）、`defeatEncounter`（对应遭遇胜利一次记一功）、`talkToNpc`（玩家实际打开目标人物对话一次记一功）。谈话信号只由场景的 `openDialogueWith` 发出：**F 键交谈**与**对无名录/无商店 NPC 的 E 键交谈回落**都算谈话；**E 键打开任务告示板不算**，接取差事的同一次交互也不会自动完成谈话目标。
- **互斥分支**：声明相同 `exclusiveGroupId` 且前置完全一致的任务构成一次玩家选择，装配时整组校验（有效成员 ≥ 2）；本轮药道组选项同列在白鹭洲的告示板，接取其一，其余已解锁成员立即记为失败（`failed`），各自后续只由对应选择解锁。
- **失败条件**：`failOnEncounterIds` 声明的遭遇一旦战败，该差事立即失败；放弃进行中的差事同样记为终态。
- **状态与存档**：全部复用 `locked/offered/active/completed/failed` 五态与按目标 id 存储的 v1 快照，无新存档字段。
- 本页总表、分支路线与遭遇表由 `npm run audit:round-34` 对照 `data/base/quests/round-07-quests.json`、`data/base/battles/round-05-encounters.json` 与 `data/schema/quest-set.schema.json` 核验：任务名、发布人、前置、目标 kind、失败遭遇与奖励任一漂移都会使审计非零退出。

- **路线差异**：A 线（护送过桥 → 庄里致谢）合计经验 85 / 银两 50，偏人脉与历练；B 线（修桥通渡 → 清扫桥头）合计经验 77 / 银两 93，偏实利酬劳。两条后续只认各自的分支选择。
- **Round 42 主线差异**：两家证词都只记下潮时与旧船印，不以单一线索定罪；「渡籍水痕拓本」为不可买卖的普通任务物。公开立册通向「公簿昭潮」，先护证人通向「灯下留痕」；两个结局都要求完成对应谈话目标，并在谈话中明确记录该路线见闻。
- **战败失败**：「雾夜巡岸」「先保药队」「栈桥通渡」（连同旧「巷口除患」）都在 `failOnEncounterIds` 中声明了对应遭遇——战败即差事失败，不提供原地重试。

## 章节叙事

### 第一章 · 巷陌与口信（方格试炼场）

巷口的刀客惊扰镇西之后，马尚义继续张罗伤者的药与疮口（巷口送药 → 灯下问药）；茶棚、书铺各有一桩随手可做的小事（茶棚凉汤、书铺驱蠹）；姜百味的货担要回程，一句改走水路的口信须当面带到（货郎口信）；顾夜尘看出你招式缺狠劲，一页荐帖把线牵到渡口刀场（路旁荐帖）。四条线彼此独立，开局面板即可接取。

### 第二章 · 药庐与渡籍（雾雨渡口）

容素青的药案串起问药与备药（灯下问药 → 药庐清点）；白鹭洲的渡籍被雨泡坏，寒山书院的教习柳听澜誊正用印，学生们熬夜抄档又熬垮了精神（渡籍补录 → 书院夜课）。河灯之约则从茶棚的旧约出发，落在渡口的水面上。

### 第三章 · 药道抉择（互斥分支）

闻素心先要巡清北岸的探子（雾夜巡岸），石北才肯发药队启程的最后一步（药队启程）。此后雾渡药道走到岔口：渡董白鹭洲把两条差事同时挂上告示板，转述石北主张**先保药队**硬闯芦苇水路，也列出自己主张的**先修栈桥**方案，让玩家在同一处比较选择；接下一条，另一条就此封止。A 线的后续是云隐山庄挨家挨户的当面致谢（药队答谢）；B 线的后续是清扫桥头自称管事的索银人（栈桥通渡）。

### 第四章 · 耳目与勘验（收束）

顾夜尘要摸清药道往后安不安生，分别去问刀场与书铺的口风（江湖耳目）；祝九弦收帖后按刀场规矩让你自备淬料（刀场淬料）；药队启程之后，叶庭舟布置师门勘验——拳脚之外，还要认得人、认得药（师门勘验）。

### 第五章 · 水痕与对页（原创主线，Round 42）

「渡籍补录」完成后，白鹭洲请玩家把正本与书院副本对页（旧簿验痕）。柳听澜看出誊副前已有异样，但不肯凭纸痕推断人名，于是请玩家分别询问熟潮时的顾夜尘与认旧船印的祝九弦（两家对页）。两份口述指向同一张旧压纸，顾夜尘让玩家拓下一份不可买卖的「渡籍水痕拓本」（封存水痕）。证物留存后，玩家在白鹭洲处决定把副册公开交柳听澜立档，或先由祝九弦保护证人与拓本；两条互斥路线分别落在「公簿昭潮」与「灯下留痕」。叙事只确认有水痕、潮时与旧印的疑点，不预设真凶，也不把尚未对证的猜想当作定案。
