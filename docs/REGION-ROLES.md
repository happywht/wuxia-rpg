# 地区角色与行旅指南（Round 106）

## 二十二既有区域

角色是本阶段设计分工，不是地形封锁、章节强制顺序或完整体验验收。元数据在world-map.regionGuides，旧资料可省略。建议不发物、不改天气、不接差事或传送。

| 地区 | 角色 | 行旅建议 |
|---|---|---|
| 江南道·七镇行旅 | 枢纽 | 先在镇中接口信、补药与问纸墨，书院可拜师；出镇前用活动差事导航核下一步。东行石阶渡口去雾雨渡口，誊正后不必再跑公所才领谢仪。 |
| 雾雨渡口 | 枢纽 | 公所接续渡籍与药队差事，名录导航跟人物当前去向。渡口无药铺；缺生命或内力药先查补给页的回镇路线，再考虑北口山路或南渡海路。 |
| 铁嶂北道·岩关驿镇 | 调查 | 分开核界石与更簿，再定署名取舍；西道接盐道，断云北隘接云岭。此地无药铺，跨区补给会显示关口数，不等于旅程分钟。 |
| 西陲盐道·青岩驿 | 调查 | 先核井壁再应对拦路者，留药救急与自备山路各有代价；回铁嶂后可接云岭。此地无药铺，出发前留补给，药量以背包与商铺实数为准。 |
| 云岭古道·断云栈道 | 调查 | 先看刻痕再过断索、问沈雨霁；三地对照后选北台或青帆埠，不把两章都当当前差事。此地无药铺，向青帆埠可补给，回关仍可原路走。 |
| 东海群岛·落潮湾 | 过境 | 落潮湾承接渡口南渡与列岛路线，先看灯标与已知地标再择去向。无本地药铺，查补给页的已装配关口路线；没有自动航行。 |
| 东溟海岸·青帆埠 | 枢纽 | 青帆埠有潮行补给摊；先补药、核东汊潮线，再赴风回岛。回望云岭接大陆，涉潮登岛接海路；活动差事和人物位置会按当前时段更新。 |
| 东溟外海·风回岛 | 调查 | 灯号调查与守灯人询证分步做，再向潮生屿或澜心洲；此岛无药铺，不能把灯标当商铺。若缺药，补给页列最近关口路线。 |
| 南溟·潮生屿 | 挑战 | 低潮礁道有实际条件与夺货挑战；药囊库存有限，先看余量再决定把药给谁。礁道、守灯与渔户顾虑不因一场胜利全部消失。 |
| 西南列岛·雾航湾 | 过境 | 雾航湾连接列岛与中溟礁路；先核当地见闻和去向，不把未见地标当已知。无本地药铺，返程和补给按关口实图导航。 |
| 云岭北台·雁回崖 | 过境 | 雁回崖接云岭、照雪关与天门关，候雁不能代替北境火号。核当地记录后再选北上或东行；此地无药铺，先查补给跨度。 |
| 北境·照雪关 | 挑战 | 高寒北境春季也可能落雪，烽燧仍须黄昏、入夜或子夜调查；晴日可等候跨日，落雪并不保证次日出现。先核烽记、应对冒号客、回谷照雪报告。南口长道暂无补给，出发前留药；西冰桥(3,64)去霜松谷，南口(49,97)返雁回崖。R→出区选择真实关口；已知地标只作调查位置。 |
| 北境·霜松谷 | 调查 | 界标旧刻、清场与报告分开推进，前朝大梁不是今朝疆令。无本地药铺，返回照雪关继续北境对照；公开注记与私记的后果由实际对白处理。 |
| 东隅·天门关 | 过境 | 天门关接北台与海东高路，南下经雾杉关接照叶港，海路接引航礁。先在出区页辨目的地；没有本地药铺，跨关补给是步行路线。 |
| 南溟·归帆洲 | 过境 | 归帆洲灯标指回港路线，联接照叶港、潮生屿与环礁。先查已知地标和关口，再选下一段；无本地药铺，潮路不自动替你备药。 |
| 东境·雾杉关 | 过境 | 雾杉关是天门关至听杉谷的林门，风铃石是方向调查。记录所见再往谷里走，回程仍用关口导航；此地无药铺。 |
| 东境·听杉谷 | 调查 | 听杉谷核溪边潮痕，分辨山路与海路记录，再赴照叶港。无本地药铺，原路北返与港口南行均在出区页可查。 |
| 东溟·照叶港 | 过境 | 照叶港接森林与归帆洲航路，不等于已有补给摊。先问船渡去向、核已知地标；缺药查最近已装配药铺，不凭港名假定商店存在。 |
| 中溟·千里石塘 | 调查 | 千里石塘分看灯序与潮时，核实后再择雾航湾或南溟方向。无本地药铺，能到地标不代表满足见闻条件；返程以出区关口为准。 |
| 南溟·半月环礁 | 过境 | 半月环礁以潮祠与东栈接续归帆洲路线，先查已知调查与出口。无本地药铺；退潮条件不足时等候，导航不改变潮位。 |
| 东溟·澜心洲 | 调查 | 澜心洲先核潮痕与观汐台、回季无潮报告，再去引航礁校灯谱。无本地药铺，最近补给通常在潮生屿，余量可耗尽；出区分别指风回、潮生与引航礁。 |
| 东溟·引航礁 | 调查 | 引航礁灯谱与航标各自核证，再返回澜心洲谈传航范围。这里不是补给港；出区接澜心洲或天门关，尚未满足的调查条件不会被导航跳过。 |

## 操作与真实验证边界

探索按R查看补给、活动差事、人物、出区、已知地标、说明；左右切分类，上下选择，Enter只设步行导航，Space翻完整详情，R/Esc收起。F交谈、E交易/关口，同行P→T。公开或已发现地标才列出，任务下一步沿用Q解析；非空间目标不伪造导航点。

本轮已真实键盘验证江南起点到姜百味补给的三格步行、正常购买清心丸后余量5→4、正常菜单保存与重载检查点、入口/分页。六地完整旅程、最长无决策路段、往返节奏与代表区域截图仍待整体验收，静态报告不代替实走。浏览器证据见iterations/round-106/playtest.md；不因二十二角色表或测试通过关闭goal。
