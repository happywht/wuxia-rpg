# Round 74 舆图浏览器验证

日期：2026-09-29
环境：Codex 隔离开发页 `http://127.0.0.1:5189/`（标签 4）

## 操作与结果

1. 在当前游玩页按 **M**，舆图总览打开；能看到五个区域标记、跨区路线和右侧地点说明。
2. 在地图视窗内滚轮放大，随后再滚动数档；大陆底图、地貌和路线同步放大，说明面板保持在右侧视窗之外。
3. 放大后在地图视窗内从屏幕坐标 `(220,490)` 拖到 `(320,490)`；海岸与区域标记随拖动平移，地图内容仍裁切在舆图窗口内。
4. 按 **G** 切换到当前江南道的 100×100 细图，再按 **G** 返回舆图总览；按 **M** 关闭面板，回到进入试玩时的场景。

以上验证确认 M/G、缩放和放大后的拖动可操作。本轮没有在浏览器手动走到云岭、接取两项新差事或完成战斗；这些区域间旅行与内容引用由 Round 74 专项回归检查。此次手测只在隔离端口 5189 操作，未切换或修改 `http://127.0.0.1:5178/` 用户标签页，也未触碰用户存档。
