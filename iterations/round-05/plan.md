# Round 05 计划

## 本轮目标

将角色成长与武学数据接成一场可实际游玩的回合制战斗：玩家可在地图上靠近遭遇点、用键盘选择已掌握武学行动，与数据定义的敌人交手，并获得胜负/撤退结果与经验奖励。战斗规则保持 Phaser 无关；场景只负责加载、触发与呈现。暂不做队伍、多敌人、状态异常、装备修正或战斗存档。

## 用户故事

- 作为玩家，我希望能在地图上触发战斗，看到双方生命/内力、选择武学行动、承受敌方回合，并获知胜负。
- 作为资料作者，我希望通过 JSON 定义武学的战斗作用、角色起始掌握的武学、遭遇地点/敌人/奖励，而不在场景代码里写人物或剧情。
- 作为后续系统作者，我希望通过纯逻辑 API 推进回合、解析伤害/治疗/内力消耗/逃跑/结算经验，并以临时脚本检验边界条件。

## 验收标准

1. 在现有 martial-art 契约中加入 schema 校验的战斗行动数据（攻击/恢复、作用值、内力消耗）；角色模板以数据列出起始掌握武学，运行时状态复制该列表。
2. 新增遭遇集合及 draft-07 Schema，至少一场原创遭遇包含地图邻接触发位置、原创敌人属性/生命/内力/武学、胜利经验、失败恢复规则与原创提示文本；地图、人物模板、武学与敌人武学引用均做跨资源检查。
3. 实现 Phaser 无关战斗状态机：玩家与单个敌人交替行动；攻击伤害、治疗、内力消耗、行动可用性、胜利/失败/逃跑与胜利经验奖励均确定且可验证；无效行动不能偷走回合或内力。
4. 场景在数据声明的遭遇点显示提示；玩家四方向相邻时按 E 开战。战斗 UI 展示双方资源、数据驱动的行动名称/文本和可读战报；方向键选择、Enter 确认、Esc/撤退行动退出；战斗打开时探索移动锁定，结束后恢复。
5. 获胜后调用 Round 04 经验系统，只发放一次奖励并更新等级/属性/资源上限；失败能恢复到可继续探索的状态；逃跑无奖励。已完成的非重复遭遇本次运行不再触发，刷新重置符合 Round 09 存档尚未实现的边界。
6. 新战斗资源或坏引用按可选内容隔离、显示可读警告，地图仍可玩；Round 03/04 已有功能通过回归。更新 `CHANGELOG.md`、`DEVLOG.md`、`ROADMAP.md`、`README.md`、GDD、架构与数据指南，构建及浏览器/临时验证通过并提交 `round-05:` commit。

## 可验证子任务

1. **战斗数据与跨资源装配**：扩展 martial-art / character-profile schema 与数据，新增 encounter-set Schema/JSON，装配时验证角色模板、武学、地图及位置；坏遭遇隔离，不影响既有切片。
2. **纯逻辑战斗闭环**：实现初始化、玩家有效行动、敌方 AI、回合交替、资源扣除/恢复、伤害/治疗、结束状态、逃跑、失败恢复与胜利 XP；用临时脚本覆盖伤害、耗尽内力、无效行动、击败、失败、撤退、经验只结算一次。
3. **键盘 UI 与地图接线**：新增一处可到达的地图遭遇点和 Phaser 战斗面板；手动验证接近/E 开战、技能选择、敌方回应、退出/胜负、探索移动恢复、有效与无效数据启动。

## 数据与规则约定

- martial-art 的 `combat` 字段为 `{ kind: "attack" | "heal", power, qiCost }`。通用引擎公式：攻击伤害 `max(1, power + attacker.force - floor(defender.body / 3))`；治疗量 `power + floor(actor.resolve / 2)`，上限不超过 health.max。内力不足的行动不消耗回合。
- `character-profiles` 新增 `startingMartialArtIds`；初始状态将其复制到运行时角色。模板引用的武学必须存在、未被禁用并满足模板的等级/属性/门派条件。
- 遭遇集合用稳定 id 连接触发位置、玩家模板、单个敌人、敌人可用武学、胜利经验、失败恢复比例与全部提示文本。遭遇位置必须在地图可走格、不得与玩家出生点或 NPC 重叠；只接受四方向相邻触发。
- 玩家与敌人每次行动后轮替；敌方在可用攻击中选择威力最高者，平手按武学 id 决胜。玩家胜利经验仅结算一次；逃跑零奖励；失败后按遭遇数据恢复生命/内力并返回探索。遭遇可按 `repeatable` 声明重复性，完成标记仅留在本次运行内。
- 单文件静态结构由 Ajv 校验；解析/跨资源失败按最小遭遇或武学范围警告并隔离。地图与 R03/R04 资源仍按现有必需/可选策略装配。

## 风险

- 战斗数值需要兼顾首轮可玩与未来扩展；本轮让威力、消耗、敌人属性和奖励都来自数据，公式保持单一、可复现，并把平衡留给 Round 45。
- 方向键已被地图移动和对话选择使用；战斗打开时必须锁定探索输入、战斗结束后正确解除监听。
- 失败/刷新/重复遭遇会涉及存档边界；本轮失败恢复与遭遇完成状态只存在内存，明确接受刷新后重置，持久化留给 Round 09。
- 当前只有单人对单敌、单目标行动；队伍、多敌人、增益/减益、装备和战斗日志归档留待后续轮次。
