# Round130 计划：寒山界刻实践与五派证据串联

## 目标与用户故事
已有四派实践的旅人可按真实退出代价改投寒山，分清纸墨与界刻所能证明的事实，正常完成沈墨涵核纸/霜松谷实访/柳听澜复命，并得到可保存的五派实际旅程证据索引。

## 验收标准
1. 从第三栏23:55:11正常读回，356银171命72气膏1/铁嶂20/善恶10江湖5。退出铁嶂按J与实际回执核算：善恶-5、江湖-50钳至0、铁嶂-40钳至0、忘本门武学。寒山资格与授艺按属性实际开放，不注入资源。
2. 副页留白正常接取→沈墨涵核纸→霜松谷旧界标实访→回柳复命。已知界标可能回填，记录回填与实际再访分别的证据；不得冒充新发现/新奖励。新简报须清楚指出人物位置、路线、气候代价与纸龄/碑龄证据边界。
3. ≥2可验证开发子任务：深化柳/沈无效果完整实践指引与作者源；严格作者幂等/漂移/跨轮重放、坐标/规则事实与场景装配回归。若实走发现通用问题，再最小修复并加测试。
4. 最大字号实测、正常第三栏存读、定向与完整构建、根日志/路线图/目标台账更新并独立commit。建立五派直接证据索引，不把五派完成代替制作/两完整构筑/其他总目标通过。
