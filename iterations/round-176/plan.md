# Round176 计划：让云岭主线可察觉断索支线

- 目标：依据云岭古道正常键盘实走证据，把已存在的断索桥调查线索接到主线行路提示中；线索范围由世界资料声明，实际调查和百科发现规则保持原样。
- 用户故事：玩家沿云岭主路行走时，经过断索桥附近能看见方向与大致距离提示，从而知道可偏路调查，而不会误以为提示本身已经触发事件。
- 验收标准：断索桥事件可声明受 schema/解析校验的可选临近半径，旧资料缺省仍为2格；临近提示按最近合格事件排序，扩展范围时附方向/格数；云岭主路(63,42)能提示东9格的断索线索，距离范围外/已发现/条件不符时隐藏；事件正文及知识节点只在实际调查时公开；资料校验、专项测试、实际UI观察与 git diff 检查通过，并提交本轮。
- 预计人类工时：≥10分钟（实走证据分析、协议扩展、回归覆盖、数据/文档更新和验证）。
- 子任务一：扩展固定区域事件的可选 clueRadius 协议、校验与提示格式；先写回归测试，覆盖旧资料兼容、边界值、方向和最近目标选择。
- 子任务二：只为断索桥资料声明10格；更新地图资料文档；在正常游戏UI实走/观察提示并核对提示不提前发现事件。
