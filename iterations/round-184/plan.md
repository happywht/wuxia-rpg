# Round184 计划：风回岛与潮生屿补给后果承接

- **目标**：承接Round183青帆埠已存隔离分支，按顾潮生的东南海口指引实际抵达风回岛、潮生屿，核验岸上/守标药品选择是否产生不同且诚实的地区回应；调查差事/潮汐门控并检查后续引航礁对照是否能汇总，而非只靠对白宣称。
- **用户故事**：玩家在青帆埠做出仅能救助一方的补给决定后，可沿明确海路听取风回岛与潮生屿人物的具体反馈，理解未获药一方仍等待补给；在潮生屿按实时潮汐完成可接续的调查，再将地区证据带回合适人物处核对。
- **验收标准**：
  1. 仅操作`http://127.0.0.1:5181/`与现有隔离槽；读回Round183的守礁分支，记录状态、出发点和未获药方。5178保持未触碰。
  2. 从青帆埠东南关口(91,71)经正常舆图/移动抵达风回岛，按人物导航听阮回澜对守礁分支的地区后果；从东岸(97,50)前往潮生屿，听岑隐礁回应/核急药份额。记录实际格数、游戏时间、对白及未获药者状态。
  3. 接/追踪「潮生屿水则」或本场景可接续任务，遵循现场低潮门控调查(26,56)，回风回岛向谢照汀复命；核对经验、见闻与重复互动幂等性。若当前条件无法合法满足，记录阻挡与条件，不绕过。
  4. 如可以安全使用已存在的岸上分支槽2，则只读比较阮回澜/岑隐礁的相反反馈；不得为了比较覆盖任何既有存档。若旧档位置无法正常接近人物，记录为未完成。
  5. 调查保存失败的真实原因；若是操作误读，按完整覆盖确认流程重存并正常读回，不改动没有复现缺陷的代码。更新计划、实走、验证、玩家手册、项目目标、CHANGELOG/DEVLOG/ROADMAP并独立提交。
