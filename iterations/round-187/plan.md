# Round187 计划：引航礁传航回响与澜心补给往返

- **目标**：从Round186保存读回的5181第三栏引航礁检查点继续，查明此存档的传航决定及其人物后续回应；按正常R导航返回澜心洲季无潮补给摊，实测库存/价格、药品预算、行走与关口时间，依据实际需求决定是否补给并验证存读。同步形成澜心—引航礁这一段可比较的区域节奏基线，为六区统一实测补证。
- **用户故事**：玩家在引航礁核准灯谱后，能复核自己此前选定的传航范围和各方承担的代价；若缺药，可按明示路线回澜心洲补给再继续，而不用猜商铺库存或人物时段。
- **验收标准**：
  1. 只读正常加载5181隔离第三栏，记录Q任务、B资源、R人物/见闻、传航选择标记及三名关键人物的当前对白；以界面或稳定知识回执确认该存档实际选的是公开/熟船/尚未选择，避免将旧轮其他存档分支套用到本栏。传航选择若尚未作出，只展示成本/选项，不代用户作不可逆选择。
  2. 从引航礁通过正常关口与R行旅实走至澜心洲季无潮当前时段所在位置；用E/F实际查看补给库存与价格、可购数量，记录每段成功格、失败输入、过关耗时、连续无互动距离及NPC换位。按角色当前物资/任务需求作出合理购买或明确不购买，并记录选择依据。
  3. 在第三栏正常保存、返回主菜单并读回，核对地图/坐标、库存/货币、关系或传航状态和已完成任务。5178、槽1/2保持不动。
  4. 依据实测决定是否需要游戏代码/数据/UI修复；若问题可复现则实现最小修复、补专项验证并正常复走；若无问题则不为凑改动改玩法。更新六区证据矩阵或相关区域指南、玩家指南、项目目标、变更/开发日志和路线图，独立round-187提交。
- **预计人类工时**：≥75分钟（存档检查、传航回应复核、多段真实步行、时段人物定位、商店盘点/合法交易、往返路线记录、保存读回与证据整理）。
- **子任务**：
  1. 实际核对第三栏传航状态、材料与季无潮/虞星槎/沿岸人物回应；未选时不替玩家选择。
  2. 从引航礁实走至澜心摊并盘点库存价格，测往返/关口/空走，按当前补给需要决定购买。
  3. 第三栏存读复核资源和任务后果，更新六区节奏证据与相关文档并完成提交。
- **涉及文件**：`iterations/round-187/*`；有实际证据时更新`iterations/round-173/evidence-matrix.json`与六区矩阵审计、`docs/REGION-ROLES.md`、`docs/PLAYER-GUIDE.md`；`docs/PROJECT-GOALS.md`、`ROADMAP.md`、`CHANGELOG.md`、`DEVLOG.md`。只有复现缺陷时才改相关src/data/tests。
- **风险**：当前保存点在NPC日程会变的引航礁；季无潮也按时段换位。存档可能已拥有完整药品或已完成传航选择，购买/改选可能浪费资源或损坏对照。以Q/B/R及当前F对白为准，所有可选后果先读清楚，避免重复扣费；只在第三栏保存。
