# Round189 计划：复现并定位澜心银两差异

## 本轮目标

围绕Round188实机发现的573→372银两差异，用隔离档与逐操作可见证据确定是否为存档读写、商铺交互、导航/输入节流或其他行为导致；如果无法复现，划清现有证据能证明的边界，为下一轮提供可执行的复现机制。继续服务统领目标：深化串联已有江湖体验，保证可复玩及独立交付；不以猜测或注资掩盖状态异常。

## 用户故事

作为玩家，我希望在澜心走访补给点时银两变化可解释，交易前后显示一致，正常读档不会无故改变资产；作为维护者，我能据真实操作和存档差异复现异常，修正后用同样流程验证。

## 验收标准

1. **只读追踪**：检查角色运行态银两的所有写入点、交易扣款、地图切换与存档序列化/反序列化路径；建立操作→预期写入点清单，区分已有代码证据与实机推断。
2. **隔离实测**：仅用`http://127.0.0.1:5181/`独立测试档，先记录slot3读取前后银两、位置、时间、背包和商店库存；逐次执行单步移动/打开面板/导航/跨图/进出商铺/取消购买/重进及保存读回，每个步骤前后都记录可见银两和库存。所有键盘操作慢速确认成功坐标，明确不修改5178用户存档或隔离slot1/2；绝不注资。
3. **结论分级**：如能复现，定位最小致因，修复对应引擎/数据缺陷并增回归；如不能，保存能取得的对照记录并明确未复现范围、未检查项及下一次更窄的复现假设，不猜成因。
4. 更新Round189实测/验证文档、持续目标、CHANGELOG/DEVLOG/ROADMAP/玩家指南中受影响内容；运行专项测试、数据Schema、六区证据、Round34/48文档审计与适用的构建/回归；审阅仅含本轮的diff并提交`round-189: ...`。
