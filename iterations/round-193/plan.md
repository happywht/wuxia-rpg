# Round193 计划：从已验证存档推进海路差事与出镇首段

## 本轮目标

从 Round192 于独立origin `http://127.0.0.1:5200/` 验证的槽1检查点继续，推进现有首档旅程。先明确活动差事「灯痕避礁」与离镇条件，再用R/M导航穿越江南至雾雨渡口及落潮湾，实查白沙灯标；同时观察系统是否如实呈现出镇通路与跨区关口的步行/耗时/关口交互规则。若此轮实走未能达到目标，记录实际坐标和未完成段，不拼接其他origin证据，不声称到达。

## 用户故事

作为正在七镇行旅历练的玩家，我能从已保存的首差事进度出发，跟随游戏内地图和差事导航前往指定海路地标，读出白沙灯标潮痕并取得后续线索；沿途知道何时必须徒步抵达出镇关口并主动交互，且差事状态和航路发现可继续保存。

## 验收标准

1. 从主菜单Continue正常载入5200槽1，核对角色/任务/位置；不触碰5178与历史origin。
2. 记录接取/追踪「灯痕避礁」的任务与R导航状态，确认下一空间目标实际解析为白沙灯标，而非行旅面板预选的药铺/其他条目。
3. 按舆图和关口资料真实步行到石阶渡口，记录坐标变化、被阻格、消耗时段及关口触发方式；与当前舆图给出的64格首段和R页45分钟过关提示分开记录，检验这两类提示分别代表什么。
4. 通过当前版本真实可用的雾雨渡口与海岛关口路线抵达落潮湾；在灯标按E调查并用Q/百科确认任务计数及知识发现/奖励；全程记录成功到达的各地图与坐标。
5. 在关键检查点正常保存并主菜单读回，核实差事完成态、发现状态、人物地点与资源仍保留；若本轮跨度不足则只保存经验证的安全检查点，准确记录尚未走的路段。
6. 更新实机、验证、路线和总日志，执行针对性数据/内容/审计；形成只包含Round193所需文件的独立提交，大目标持续active。

## 子任务

1. 从已验证槽1读取检查点，区分活动差事目标、引导面板默认选择、全图路线估算、当前地图本地路线和出镇交互提示；建立实机基准。
2. 实走江南区域至石阶渡口和雾雨渡口，记录每段坐标、时间变化、关口耗时、界面反馈和地图加载。
3. 实走落潮湾白沙灯标调查与任务/百科状态，并执行正常保存读回；无法完成则留下准确续行状态和明确阻断。
4. 更新路线图、变更日志、开发日志及验证文档；复核差事/舆图资料引用并提交。
