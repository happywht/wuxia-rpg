# Round 200 计划：石涧事件的真实资料图谱回归

- **目标：** 将Round199发现的事件百科问题从通用选择器回归提升为真实世界资料集成回归，验证区域事件触发前后知识可见性的实际因果。
- **用户故事：** 我沿任务线认识石涧淡泉并亲自到达后，百科能够记录“寻泉事件”及其与地点的关系；触发前未探索的事件不会提前曝光。
- **验收标准：** ①从正式world-map和知识图谱JSON读取Round87石涧事件；②触发前事件节点未知且对应边不可见；③使用当前通用事件发现规则模拟实际触发后，事件与地点节点都被发现、`kg.edge.r87-spring-event`可见；④保留已知地点、重复触发幂等、资料声明的发现目标语义；⑤定向测试、类型和资料Schema验证通过，手测边界如实记录，单独round-200提交。
- **子任务：** ①建立真实资源驱动的百科关系投影回归，避免只用手工构造节点fixture；②运行Round87/90相关回归、类型和Schema检查；③更新Round200计划/验证、项目目标与日志路线图并提交。
- **涉及文件：** `tests/round87-southwest-isles.test.ts`、`iterations/round-200/`、`CHANGELOG.md`、`DEVLOG.md`、`ROADMAP.md`、`docs/PROJECT-GOALS.md`。
- **风险：** 5181独立测试浏览器标签聚焦超时；禁止刷新未保存的5200实机进度。本轮集成测试不能替代修复后浏览器实机验证。
