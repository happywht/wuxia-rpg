# Round 218：接续江南送药委托与巷口战前准备

## 目标
从5204/tab31读回的抄书学徒Lv2、茶棚任务已完成检查点继续，核实背包与银两，在游戏人物索引定位马尚义，接取「巷口送药」，按目标补齐三份回春膏；若战前资源足够则推进「巷口除患」并实走击败疤脸刀客，保存/读回同一隔离槽。

## 用户故事
已完成采药差事的玩家能沿着人物线索接续送药任务，按库存和自身资源规划补给，在巷口处理威胁并持久保存战果。

## 验收标准
1. 核对当前角色位置、Lv、Q任务完成状态、B物品/银两；不依旧会话推断。
2. 定位马尚义并接取送药任务，核对实际起始所需/已有回春膏数量；交易过程确认单价、支出、交易后资源。
3. 达成送药3/3；接取后续战斗委托并依当次HUD导航逐格走至触发格，若资源/剧情允可则实战获胜并核验回执。
4. 保存至5204本人槽一，从主菜单读回核对任务/物品/位置，更新目标文档和日志并独立提交。

## 子任务
1. 复核隔离档、任务面板、背包与货币。
2. 找到马尚义并接取送药任务，补足药品、核实数量和花费。
3. 如战前可行，接取巷口除患、实走路线并完成战斗；否则记录具体阻断并保存送药检查点。
4. 保存/读回已取得进度，整理证据及目标/路线图/开发日志。
