# Round 234 计划：从补给差事转入战斗成长实走

作为刚完成补给差事的初入江湖玩家，我要能接下一个既有委托、走到现场与敌人交手，并看见战斗结果如何推动成长与任务。

1. 只在5205隔离槽一推进；确认茶棚差事完成、寒珠草和奖励仍在；5204旧档只读。
2. 与马尚义接取并完成「巷口送药」购药前置，确认「巷口除患」已解锁并接取；尝试到达战斗点，未实触发则记录为未完成。
3. 若游戏状态可信且槽一提示身份一致，保存并主菜单Continue读回核验任务、物品、成长及地图位置；任何疑点均取消。
4. 更新实机/验证文档、目标附件和路线图，运行定向战斗/任务/存档测试并独立提交。

## 可验证子任务
