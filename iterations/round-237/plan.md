# Round 237 计划：从清巷结案续走拜师与出镇

## 本轮目标
从Round236槽二主菜单读回真实检查点，实测叶庭舟关系/听雨剑阁入门条件，按正常对话完成拜师；随后循江南石阶渡口路线争取首次出镇跨区，并保存读回师承与区域状态。

## 用户故事
作为刚完成江南清巷的新弟子，我要能把行侠获得的经历和人物关系带入门派承认，再从熟悉的江南走入渡口，让开局差事、师承与大世界旅程接成一条可存档的经历。

## 验收标准
1. 5205槽二Continue读回后，Q确认送药/除患完成，B/J/HUD确认角色、关系、师门资格和位置；槽一及5204保持只读。
2. 使用R导航实走到叶庭舟，核实剑意关系≥5、入门四项条件，正常对话加入听雨剑阁；J页复核师父、门派声望和奖励。
3. 若状态允许，按任务/行旅目标实走至石阶渡口并E过图，记录真实起终位置、时间及新区域；若门槛不足或受路障限制，留下准确检查点并说明原因，不虚报过图。
4. 将本轮旅程安全保存到已确认属于Round236的槽二，主菜单Continue读回，核对Q/J/B/HUD及区域传送后的状态。
5. 更新日志、路线图、权威目标检查点，运行定向路线/派系/存档测试并独立提交。

## 可验证子任务
1. 主菜单加载槽二，检查任务、关系、等级/属性、物品和剩余银两。
2. 导航叶庭舟、先交剑意再拜师，并读取门派/资格页。
3. 按地图出口提示实走过图；将能完成的师承/区域状态写入槽二并同槽读回。

## 风险
剑阁入门要求悟性≥9、道德范围−20至80、江湖声望≥0、与叶庭舟关系≥5。门派关系与任务系统不同，不凭历史旅程估算。角色可能尚无拜师资格或身法不足以学会首个剑招；拜师成功不等于自动授艺。渡口可能需准备/满足具体关口条件，禁止盲目覆盖其它存档。
