# Round 248：师门前置追踪与海岛导航复核

## 本轮目标
从Round247保存并读回的海岛本人槽一继续，核验「师门勘验」的确切前置任务链，并复测灯标附近/障碍区的路线提示与实际碰撞是否一致。依据证据决定是否修复任务解锁提示、寻路/地图碰撞，或形成明确的下一轮验证项。

## 用户故事
- 作为门派弟子，我希望知道锁定的师门勘验具体还缺哪项差事，以及如何开始补足。
- 作为跨区玩家，我希望HUD导航给出的下一步能穿过实际可行走的海岛地形。
- 作为长期游玩的玩家，我希望专项修正有回归验证，且当前本人档案不被覆盖。

## 验收标准
1. 先从5206标题Continue读回Round247本人槽一，核对落潮湾位置、灯痕避礁完成态及师门状态。
2. 从任务数据和运行逻辑追溯师门勘验依赖的全部前置，确认本档对应的任务状态，并在UI记录具体缺项。
3. 在岛内已知树石路段用HUD建议逐步复测，记录起点、建议步、实际坐标变化；与地图碰撞及寻路代码/数据交叉核对。
4. 若能定位明确引擎/资料错误，实施修复并添加定向回归；若本轮不能修正，至少完成可复现定位证据及真实计划。
5. 不覆盖本人槽，除非已核旧摘要且有本轮必须持久化的进度；记录存档安全边界。
6. 更新playtest、CHANGELOG、DEVLOG、ROADMAP、PROJECT-GOALS及外部目标检查点，独立提交Round248。

## 子任务
1. 实机Continue及任务目录/授艺界面复核，映射锁定链条到数据前置任务。
2. 海岛路线提示与真实网格碰撞对照，识别路径抖动或障碍数据问题。
3. 编写证据与回归修复（若已达到明确可复现根因），更新长期目标记录并提交。
