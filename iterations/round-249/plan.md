# Round 249：推进师门前置的可玩链

## 本轮目标
从Round247已保存的东海群岛本人槽一出发，验证Round248“锁定差事详情显示缺失前置”的玩家可见路径；返回可到达的NPC据点，核对「药材盘点」「雾夜巡岸」「药队启程」实际接取/完成状态，并推进一项可完成的前置，让「师门勘验」逐步从目录锁定转为可解释、可游玩的任务链。

## 用户故事
- 作为听雨剑阁弟子，我希望能从师门锁定提示找到实际可接的药队前置。
- 作为往返渡口的玩家，我希望跨区域任务链有可走路线、明确交互与存档恢复。
- 作为长期游玩的玩家，我希望已完成的旧任务不会被重做，失败/战斗门槛能如实呈现。

## 验收标准
1. 在5206标题Continue读回Round247本人槽一，先核对落潮湾(79,68)、角色和任务状态，不操作旧5204页。
2. 通过海岛/渡口回到任务链所在区域；记录真实关口、耗时及路上任务状态变化。
3. 在有关NPC任务板核对三项任务的状态和Round248新详情提示；选择能实际继续的一项推进至少一个验收目标，若有完整闭环则继续结案。
4. 未达到完整安全落点时不覆盖本人槽；若保存，覆盖前核验摘要并主菜单Continue读回。
5. 更新实机记录、CHANGELOG、DEVLOG、ROADMAP、PROJECT-GOALS及目标附件，独立提交Round249。

1. 读取并核对本人槽，使用R跨区与N导航找到药队差事相关NPC。
2. 查看任务名录与任务详情，核实新前置提示，推进一项当前可接任务。
3. 保存/读回（仅有稳妥检查点时）并记录本轮边界与后续任务链。
