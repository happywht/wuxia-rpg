# Round 57 计划 — 跨区域舆图目的地接续与行路提示

## 本轮目标

修复超大可移动世界舆图的跨区行程只显示第一段、关闭面板或穿过关口后目的地即丢失的问题。玩家选定一个已经发现的地标后，行路目标在本次游戏过程中保持稳定；HUD 给出当前区域的步行方向和下一关口，玩家手动通过关口后继续向同一目的地规划。抵达、失去发现资格、目标资料失效或当前地形无法规划时，按确定规则清理并显示状态。导航只提供提示，不代替玩家移动或交互。

## 用户故事

- 作为前往远方地标的旅人，我可以在 M 舆图选中目标，收起地图后仍看到当前步行方向。
- 作为跨越多区域的玩家，我手动走到并通过关口后，HUD 和重新打开的舆图继续显示原目标在新区域的下一段路线。
- 作为只探索已知世界的玩家，导航提示不会泄露未发现的地标；目标抵达或失效后提示明确结束，我可以选别处重新规划。

## 验收标准

1. 当前区域和远方的同一地标均带稳定 destination id；已发现地标可作为舆图持久选中项，选中普通关口/区域会清除地标目标。
2. 关闭/重开舆图保留同一次运行中的目的地；在有效的定向关口切区后，按新位置重算地图路径与下一关口，行程名称仅覆盖已发现地标。
3. HUD 在不覆盖时间、天气、地图名、任务和交互提示的区域显示当前可执行行路提示；手动控制与原来的关口 E 交互语义不变。
4. 抵达本地图地标（可走地标抵达格子本身，阻挡地标抵达两格内的可行近点）、地标失去可见资格、地图/关口路线消失或本地地形不可达，都会确定地清空目标并给出非误导状态；不更改存档协议。
5. Phaser-free 测试覆盖 id 重映射、已知门控、跨图区段重算、抵达和失效；旧舆图 waypoint 构造仍可不传选择项。
6. 同步玩家地图指南、架构/舆图说明、CHANGELOG/DEVLOG/ROADMAP；执行专项测试、完整质量门槛和发行包 smoke；提交 `round-57: 接续跨区舆图目的地`。

## 子任务

1. **导航目标模型与纯逻辑验证**（约 35–45 分钟）：为公开地标 waypoint 增加稳定目标 id；新增 Phaser-free 解析器，按当前世界、当前区域和知识门控解析本段目标/下一关口并判断到达与失效，测试两张真实地图的往返/门控/不可达边界。
2. **舆图与探索 HUD 闭环**（约 40–50 分钟）：让舆图在选点时通知场景，重开自动恢复同一地标的本区 projection；移动停步与成功切区后刷新路线，展示导航提示、到达/失效清理；验证关口继续由玩家手动交互。
3. **文档、回归与发行**（约 35–45 分钟）：更新地图指南/引擎说明/玩家手册、迭代记录和 50+ 后续路线；执行专项、全量校验/测试、文档审计、Vite 构建和发布归档 smoke，复核 git diff 后提交。

## 风险

- 舆图地标目标应使用稳定的地标 ID，而不能复用会因本地区域/远方投影改变的 waypoint ID。
- 只按成功完成的关口切换更新区域行程；被 NPC/遭遇挡住的失败切换不能改变路线状态。
- 知识门控过滤必须先于提示文字生成；切区观察到的新地点不可让未发现目标在 HUD 闪现或预告隐藏内容。
- 主场景 HUD 有紧凑的小屏纵向空间；行路文字须限长并占用左上空位，保留右上气候信息和底部 E 交互行。
- 导航路线是建议且不写入旧版存档；刷新/读档后玩家可在舆图重新选择，不触碰既有 v1 存档字段。
