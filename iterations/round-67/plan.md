# Round 67 计划：扩建西陲盐道与全域舆图

## 本轮目标

把当前三块可玩区域扩展为四块：新增完整的 100×100「西陲盐道」区域，接入现有铁嶂北道旅行网络，并将可移动全域舆图扩展到更大的画布、调整区域布局。新区域必须具备可走道路、地标、资料驱动的人物/事件/任务内容，而非只添加一个总图标记。

## 用户故事

- 作为正在探索江湖的玩家，我希望能从铁嶂北道进入一片新的边陲盐道，在真实可走的道路上发现驿站、人物与差事，再沿关口返回原有区域。
- 作为玩家，我希望全域舆图能展示更辽阔的四区地理关系；地图大于视窗时，仍可通过拖动、缩放与方向键查看各地，并能从总览切换回当前区域细图。
- 作为资料作者，我希望新增区域、关口、人物、任务、地标和舆图位置都由 JSON 声明，继续使用已许可的 CC0 像素图集，不需要在引擎中添加具体世界观硬编码。

## 验收标准

1. 新区域通过现有数据 Schema，可从世界入口抵达；至少一对双向关口连接铁嶂北道，出生点、关口、地标、事件、NPC 日程和遭遇锚点均在 100×100 碰撞图上可走且从入口连通。
2. 新区域含有可辨识的道路与盐地/驿站地貌层、至少三个地图地标、两项资料事件、至少一名可交互人物、一条可完成任务及一场可重战遭遇；对白、奖励、知识图谱关系和空间坐标均由数据驱动。
3. 全域舆图扩至至少 160×112 格，四区锚点均在连续陆地上，真实关口均映射为连线；全域视图拖动、缩放、裁切与本区细图切换继续通过自动回归及浏览器试玩。
4. 新旧区域、旧存档与缺少可选 `atlasArt` 的兼容行为不回归；新增/变更资料通过 Schema 和文档一致性审计，素材仅使用仓库内已有 Kenney CC0 图集。
5. 更新本轮计划、`CHANGELOG.md`、`DEVLOG.md`、`ROADMAP.md` 与地图/区域/任务/玩家指南；运行定向测试、完整质量门槛与发行包验证，记录真实命令及结果，并创建唯一 `round-67:` 提交。

## 子任务

1. **新区域可玩闭环**：检查地图与 NPC/任务/对白/遭遇 Schema，编写确定性区域生成器；注册新百格地图、关口、地点、事件、人物/日程、对白、差事、遭遇和图谱关系；验证所有空间锚点连通及新任务闭环。
2. **大舆图扩建与集成回归**：调整四区总图坐标，扩展 Kenney CC0 总图尺寸和地貌/关口路线生成；补齐专项测试和地图体验/数据说明；执行数据审计、全量测试、发行构建及浏览器手动验证。

## 风险

- 扩大生成式底图并重新排布既有区域可能改变地图标记的缩放/边界语义；使用共享投影函数和多尺寸浏览器检查防止标记漂移或无法平移至边缘。
- 新增关口可能造成区域入口落在障碍上，或盐道主路的装饰生成意外覆盖 NPC/事件锚点；生成器应保护锚点并对入口到全部目标执行连通性验证。
- 总图图层和数据包体会随画布扩大；新尺寸须同时受 Schema 与运行时限制，并以生产发行验证其可加载性。
- 复用图集中的盐地/驿站素材前核对瓦片和授权白名单；不引入来源不明或未授权的素材。

## 预计人类工程师工时

约 90–120 分钟，包含区域生成器与资料装配、跨区连通性/任务测试、总图放大与重新布局、文档更新、完整质量门槛和浏览器手动验证。
