# Round 79 计划：第六区域与 CC0 海岛图素

## 本轮目标

把当前五个百格区域、208×128 格的可移动舆图扩展成更大的六区江湖，并为新增沿海区域接入网页核验过授权的 16×16 CC0 像素图集。继续保留 M 舆图的拖动、滚轮缩放、方向键平移、总览/区域视图切换及路线投影；新增区域通过可步行的双向关口接入现有世界。

## 用户故事

作为玩家，我希望从现有山河继续走到有海湾、岛屿和渡口的新区域；打开舆图时能看见扩大的大陆轮廓，并可拖动、缩放到新区域。新区域的地貌和人物来自明确授权的像素图素，而不是临时手绘占位。

## 验收标准

- 默认世界新增第六张 100×100 可玩地图，碰撞/地貌/美术各自数据驱动；江南/雾雨渡口至新增区域存在可步行的双向连接，区域入口和出口可达。
- 新增区域接入全域舆图、已知地点投影与数据清单；总图扩大且新区域在初始总览中可辨认；现有五区、坐标、门路和旧存档地图 id 不变。
- 从 OpenGameArt 的 **16x16 Puny World Tileset** 页面核验作者 Shade 与 CC0 许可；保留来源通知，只把新增地图实际引用的原始像素图集及许可说明纳入数据/发行清单。
- 至少三处沿海/聚落地标和一位本地 NPC；新增一条可接取并完成的短任务，资料均通过 Schema 校验，剧情文本不进入引擎。
- 自动测试验证地图尺寸、路线/碰撞可达、图素引用范围、关口往返、舆图区域投影、来源许可记录及旧地图/MOD 回退；专项与完整质量检查通过。
- 隔离浏览器中实测新区域美术、M 总览、拖拽平移、滚轮缩放、G 区域细图和新关口/地标显示；检查不同视口下画布与舆图可用性并记录边界。
- 更新 `CHANGELOG.md`、`DEVLOG.md`、`ROADMAP.md`、`README.md`、地图/素材/测试说明并提交一个 `round-79: ...` commit。

## 预计人类工程师工时

4–6 小时（网页素材与像素网格审查、百格地图与碰撞布局、跨区/任务资料装配、舆图扩展、回归和浏览器验证）。

## 子任务

1. 从 OpenGameArt 官方素材页核验 Puny World 图集与 CC0 声明；下载并目检实际像素尺寸/格网，记录作者、页面 URL、许可及发行边界。
2. 设计并生成第六张百格沿海区域地图，加入独立碰撞、图集/地层引用、三处地标、一位 NPC 和一条短任务；通过现有数据 Schema。
3. 将新区域和双向关口接入 manifest、知识/任务资料及全域舆图；扩展全图生成器尺寸和地貌构图，保持已有区域投影与坐标稳定。
4. 补地图/素材/旅行和旧格式回归，运行专项与完整发布检查；在独立浏览器实测总图平移、缩放、区域切换和新图像。

## 风险

- 新地图图集尺寸或格网偏差会让瓦片裁错；先目检原图，按透明边界和 16×16 基准测试引用范围，再确定地图帧号。
- 海水/陆地的视觉边界与独立碰撞若不一致，会造成可见地面不可走或角色能走进水里；生成后对出生点、海岸入口、NPC 和出口执行路径连通审计。
- 扩展全图若重排旧锚点会破坏路线投影或存档标记；本轮只增加新区域与画布空白，不移动既有五区坐标。
- 新地图和任务资料增加发行体积；发行只携带新地图确实引用的图片与授权文件，并通过 release 子路径 smoke 核对。
- 环境交互协议原排在 R79；顺延到 R80，路线图中会说明调整原因与新顺序。
