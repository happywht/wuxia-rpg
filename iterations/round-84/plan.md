# Round 84 计划：东溟外海可步行扩展与大幅舆图

## 本轮目标

把当前 `336×224` 世界舆图向东和向南扩展到 Schema 单边上限内的 `384×256`，以新增长约 `355,125` 格为中心的东岸岛陆呈现第八个可进入区域「东溟外海·风回岛」，并从东溟海岸可走的东南潮滩接入双向步行关口。风回岛使用项目已登记的 OpenGameArt Puny World、RPG Town 与 Puny Characters 像素图素；来源为 Shade 的 [16x16 Puny World Tileset](https://opengameart.org/content/16x16-puny-world-tileset)，页面标注 CC0。同步增加原创海岛人物和一项探索任务，继续让大地图地貌、地图碰撞和玩法内容由资料驱动。

## 用户故事

- 作为玩家，我能在仍可拖动、滚轮缩放和方向键平移的大幅舆图上看到东溟外海延展，并从青帆埠东南岸实际进入新的 100×100 海岛地图，再沿原关口走回海岸。
- 作为玩家，我能在风回岛找到新的像素人物、探索灯标地貌并领取/完成一项岛上见闻任务。
- 作为内容作者，我能用确定性生成器创建舆图延伸和新区地貌；既有 336×224 舆图格、七区中心、老关口与旧地图碰撞保持原坐标。

## 验收标准

1. 本计划先于实现写入，范围拆成至少两个独立可验证子任务，预计工程量不少于 10 分钟。
2. 总舆图扩展到 `384×256`、16 像素/格；所有既有图层在旧 `336×224` 矩形内逐格相同，七个旧区域的投影绝对中心不漂移，运行时与 JSON Schema 均接受尺寸且不超过 384 格限制。
3. 新增一张 `100×100` 风回岛地图并加入 manifest；从东溟海岸东南岸 `(91,71)` 与风回岛入岸点 `(2,50)` 建立双向关口，回程从岛上 `(1,50)` 抵达海岸 `(90,71)`。两侧端点均可走、不同于出生点和 NPC，且从各自出生点可达；返回路径通过实际步行关口验证。
4. 舆图东部增绘与新区位置相符的海岸/岛屿层；新区环境、人物和地标只引用已登记素材帧。保留 Puny World CC0 的 OpenGameArt 来源/许可证记录，不新增无来源或非授权素材。
5. 新增一名岛民、一段数据对白、一项发现型任务及知识图谱节点/边；任务目标、奖励、地标发现和人物/地图引用通过运行时装配验证。
6. 自动回归检查生成器幂等、尺寸/帧范围、旧舆图像素保留、旧区域投影、八区数量、关口双向可达、人物占位、任务流程与图谱引用；更新受新世界数据影响的旧精确断言。
7. 更新 README、ROADMAP、CHANGELOG、DEVLOG、舆图/人物/任务/素材/测试文档；运行专项与全量检查、生产构建，并在隔离浏览器尽可能验证地图平移、进入风回岛及返程，准确记录手动验证的边界；使用 `round-84: ...` 独立提交。

## 子任务

1. 实现舆图确定性扩展生成器：从 Round 81 的 `336×224` 检查点安全扩为 `384×256`，新增 CC0 东岸地貌层，保持旧图层像素和既有区域绝对投影，并覆盖幂等/上限回归。
2. 实现风回岛 `100×100` 可玩地图与两向海岸关口，核查海岸端点、碰撞、路线连通、角色和任务锚点；为海岛声明已登记 Puny World、RPG Town 与 Puny Characters 帧。
3. 为岛上人物、对白、探索任务和知识图谱资料独立建档；接入 manifest、总舆图地标/事件，验证奖励和发现效果。
4. 更新历史测试夹具、文档和 50+ 轮路线图；执行专项/全量门槛、构建与隔离浏览器操作，再按轮次提交。

## 风险

- 青帆埠东侧海湾多数格为实心水；已用 BFS 核实 `(91,71)` 是可通行潮滩，且从 `(6,50)` 出生点 106 步可达。生成和跨资源测试仍须重复证明它在新增 NPC/遭遇占位后的可达性，不能只凭外观推断可走。
- 扩图会把现有 `atlasPosition` 的百分比基准从旧尺寸换到新尺寸；必须按旧世界像素中心重算，并用精确格层对比证明七个老区不漂移。
- 384 格是舆图单边硬上限；新增 landmass 与 region footprint 必须整体留在界内，最大 zoom 时仍要由舆图相机裁切而不能遮挡信息面板。
- 手动跨区走到新岛需要在百格地图内实走；若隔离浏览器无法完成，自动路径回归可证明可达性，但日志不能把它写成浏览器实玩。
