# Round 92 计划：北境雪关与 12 区世界舆图

## 本轮目标

在现有 640×448 可移动舆图北部留白接入第十二张可玩区域「北境·照雪关」，用网页核验过授权的 16×16 OpenGameArt 冬季像素图集构成雪地、冰面与山关。沿「云岭北台·雁回崖」建立真实双向步行关口，加入守关人物、调查差事和图谱见闻；旧三十三层舆图、十一区坐标和现有画布尺寸保持不变，并验证旧轮次生成器可以在 Round 92 资料上安全重跑。

素材候选来源：[OpenGameArt — Winter Tileset [16x16]](https://opengameart.org/content/winter-tileset-16x16)，作者 zaphgames，页面标注 CC0。本轮实施前核对实际 PNG 尺寸、像素帧与下载包许可，仅将游戏实际引用的 PNG 和许可/来源说明纳入发行白名单。

## 用户故事

- 作为沿雁回崖北行的玩家，我能穿过山口进入有独立雪地与冰川图素的北境区域，再沿另一座关口步行返回。
- 作为探索北境的玩家，我能认识一名守关人，调查一处与旧烽火有关的地点并完成一项有发现奖励的任务。
- 作为地图维护者，我能重跑本轮生成器及 Round 87/91 生成器，而不会丢失后续区域、图层、关口或地标。

## 验收标准

1. 计划先于实现落盘；本轮拆分至少三个可验证子任务，工程量超过 10 分钟并更新逐轮记录。
2. 舆图仍为 640×448 格；前 33 层逐格与 Round 91 基线一致；新增北境图层只在选定的北部新区域投影内绘制，十二处区域标记可辨且不相互覆盖。
3. 新增一张 100×100 网格地图和 CC0 雪地图集，碰撞独立于绘图层；云岭北台双向关口、出生点、NPC、调查点与返程关口均有可行路线。
4. 新 NPC、原创对话、至少一条含目标/奖励的任务、固定事件和知识图谱关系均为独立数据资源，并通过 Schema 与跨资源引用审计。
5. 新素材来源 URL、作者、CC0 许可、用途和发行范围登记在 `docs/REFERENCES.md` 与发布白名单；只打包运行时引用素材。
6. 新生成器确定性幂等；在 R92 状态重跑 Round 87、91、92 生成器后，R92 区域、层、端点和知识资料不丢失。
7. Round 92 专项、`npm run check`、`npm run build`、`git diff --check` 通过；浏览器检查 M 舆图新标记、拖动/缩放/Home/选点，并实走北境往返关口，结果与证据记入日志。
8. 更新 `CHANGELOG.md`、`DEVLOG.md`、`ROADMAP.md` 及相关世界/地图/任务/素材文档；以一个 `round-92: ...` commit 提交。

## 子任务

1. 查验 OGA 页面和文件许可、PNG 像素尺寸及可用帧；建立新区域雪地调色/拼接原型，锁定不覆盖旧地图的北部位置。
2. 创建确定性雪关地图/舆图生成器、独立碰撞网格、区域地貌层和 R91—R92 两向关口；守护旧三十三层哈希及十二区投影。
3. 接入守关 NPC、对白、调查差事、一次性见闻、图谱节点/关系和发行资源；增强 R91/R92 专项以验证两向步行路线与资源闭合。
4. 检查 M 舆图与雪地角色观感、实走跨区往返；更新授权及玩法文档、运行全部门槛并复核仅本轮文件进入提交。

## 风险

- 北部地貌层必须先检查与所有旧层及既有区域标签的空间关系；新增图素不得改写旧图层像素或把地标推到舆图视口边缘。
- 冬季素材色板可能与当前 16px 山地/角色素材不协调；需先看原图与实机组合，再决定图块缩放或弃用，不得用未经授权的素材填补。
- 旧生成器的重跑路径可能规范化未知数据；逐轮生成后必须比较本轮资源和新增图层，发现丢失才调整对应生成器。
- 舆图已到 640 列 schema 上限，本轮禁止变更画布尺寸，避免改变历史投影、图集与视口预算。
- 浏览器实走会推进本地测试角色时间与位置；记录新角色/新存档范围，避免把未完成跨区流程误记作已通过。
