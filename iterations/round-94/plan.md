# Round 94 计划：拓展东境与南溟可步行世界

## 本轮目标

将资料驱动的可移动全域舆图从 **640×448 格**扩展为 **768×576 格**，画布面积增加约 54%。在东侧新增与雁回崖相连的「东隅·天门关」，在南侧新增与潮生屿乘渡相连的「南溟·归帆洲」；两处各提供可探索的 100×100 地图、NPC、原创对白、差事、区域事件和知识图谱链。舆图改用 8 源像素/格烘焙已登记的 16×16 图素，把完整大图纹理控制在约 6144×4608，降低开图内存压力并保留平移/缩放。

素材复用已目检并登记的 OpenGameArt Tiny RPG Mountain、zaphgames Winter、Shade Puny World 与 Puny Characters CC0 图集；本轮按新用途更新 `docs/REFERENCES.md`，不加入未核许可素材。

## 用户故事

- 从雁回崖东行的玩家能沿雪脊进入天门关，探索山门和烽台并沿关口返回。
- 潮生屿行旅者能在南岸乘渡到归帆洲，沿岛路调查归港标记并返回。
- 浏览全图的玩家能拖动、缩放和键盘平移 768×576 大世界，在新陆块间选点并查看跨区路线。
- 资料维护者能重跑 Round 94→93→92→91→87；旧图层像素前缀、旧区域绝对格中心与新内容仍保持稳定。

## 验收标准

1. 本计划先于实现；至少五项可验证子任务，工程量超过 10 分钟。
2. Schema 和运行时接受 768×576；舆图烘焙 tileSize 改为 8，源图集仍按 16×16 读取；相机 fit/zoom/drag/Home、标记和路线投影保持相同网格语义。
3. 原 640×448 画布内所有旧图层逐格不变；填充东缘与南缘海面并绘制东部雪岭/南部岛礁。旧 13 个区域中心和 footprint 不漂移；新中心约为 `(700.5,96.5)`、`(405.5,492.5)`，与旧区域投影不重叠。
4. 新增两张独立 100×100 `grid-map`，碰撞只由格网决定；雁回崖—天门关、潮生屿—归帆洲均有双向可达入口。两个新区域各含原创 NPC/七时段日程、对白、调查事件、差事和图谱链；Schema、跨资源引用和发行素材白名单通过。
5. 生成器确定性可重跑；R94→R93→R92→R91→R87 不丢失新画布尺寸、旧 43 层图像素前缀、15 个区域中心与任务资料。历史测试分别核对当前尺寸和冻结旧画布，不能放松旧保护。
6. 专项、`npm run check`、`npm run build`、`git diff --check` 通过；浏览器实测平移/缩放和两条跨区域路线，未实走则如实记录。
7. 更新 CHANGELOG、DEVLOG、ROADMAP、README、舆图/人物/任务/图谱/玩家说明和素材来源，并创建唯一提交 `round-94: ...`。

## 子任务

1. 核对 Schema/runtime 上限、renderer 贴图分配与 43 个旧图层；计算 footprint/地貌占位，记录逐层哈希和 13 个旧中心基线。
2. 将维度验证上限提升到 768、行列矩阵上限提升到 768；舆图输出缩为 8px/格，核验缩放相机、烘焙和标记/路线投影。
3. 编写确定性扩展生成器：pad 旧层、逐格保留 640×448 内容、绘制扩展水域及东境/南溟，并创建两张美术/碰撞分离地图。
4. 接入关口、两名有日程 NPC、对白/任务/事件/图谱；测试素材帧、入口 BFS、旧像素哈希、投影、相机和发行资产闭合。
5. 使 R93/R92/R91/R87 生成器重跑适配 768×576 与后续层；验证混合重跑顺序和逐字节稳定性，更新历史夹具。
6. 操作游戏舆图和新区域，运行专项及全量门槛、更新文档并提交。

## 风险

- Schema、运行时解析、RLE 行宽、历史生成器和许多回归测试写有 640×448；R94 顺序重跑须证明不回退尺寸或擦除后续层。
- 768×576×16 源像素会创建约 12,288×9,216 画布，单张 RGBA 贴图约 432 MiB；本轮将 overview 输出 tileSize 调为 8（约 108 MiB），仍需浏览器核验首次开图、拖动不超时或丢图。
- 东部雪岭接近雁回崖 footprint；南岛需与潮生屿、雾航湾和现有岛链分离。按 atlas cell 尺度审计，不按百分比判断。
- 新区域须有地图/关口视觉依据；南境过海用乘渡关口表达，并保证双方地图的进入和返程端点都可走。
- 已登记 CC0 不代表任意帧都适用；素材帧仍需目检占位和透明像素，只引用专项白名单帧。
- 浏览器实走可能需要从合适来源入口开始；自动化 BFS 不代替玩家操作记录。
