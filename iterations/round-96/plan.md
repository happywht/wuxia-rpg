# Round 96 计划：开通中溟环礁航路

## 本轮目标

填充 768×576 全域舆图最大的中南海域空白，并把当前长距离折返的西南列岛支线接入南溟归帆洲，形成一条新的短程海路环线。新增两张 100×100 可探索礁岛地图「中溟·千里石塘」「南溟·半月环礁」，经三段双向关口连接雾航湾、彼此相连，再通往归帆洲；世界地图中的航线从雾航湾到归帆洲由原有 8 段缩至 3 段。

新增岛屿和海路复用已登记的 OpenGameArt Shade Puny World CC0 地貌图集；新人物复用已登记的 Puny Characters CC0 图集。只使用仓库已有许可闭合的素材，不引入运行时远程资源。新增世界岛屿预计落在中心 `(190,430)`、`(295,505)`，其椭圆占地与旧图层无交叠；新海路覆盖水纹的部分属于预期叠层，必须在专项测试中单独声明并核验，旧图层自身哈希仍须逐格不变。

## 用户故事

- 从雾航湾出发的玩家能走到东岸出口，依次登上两座新礁岛，最后从归帆洲西岸登岸并按原关口返回。
- 探索环礁链的玩家能发现原创海上见闻、遇见按时段活动的人物并完成一段包含跨区调查与交付的连续差事。
- 查看全域舆图的玩家能看到中南海域由两座新岛和航路构成的地貌，沿新的海上走廊连接西南列岛与归帆洲；拖动、缩放、键盘平移、选点导航和 Home 复位保持可用。
- 内容维护者能重跑 Round 96 及旧生成器，保留新增地图、航路和资料；地图入口问题可由 BFS 专项测试定位。

## 验收标准

1. 本计划先于实现；至少六项可验证子任务，并包含代码、地图资料、文档、自动化/浏览器验证和单独提交。
2. 舆图维持 768×576、8 源像素/格；旧 57 层逐格哈希及旧 18 个区域投影中心不变。新增两座岛与可辨认海路图层，不覆盖既有地貌；水路仅能按专项测试明示规则叠在既有海水装饰上。
3. 新增两张完整 100×100 地图，碰撞与绘制分离。雾航湾 `(93,50)`、两岛往返入口和归帆洲 `(4,50)` 均从各图出生点逐格可达；新增三组双向路线、共 6 个有向关口。世界路线 BFS 可从雾航湾经两座礁岛抵达归帆洲，路线长度为 3 段。
4. 至少两位新 NPC 带七时段日程；新增至少两阶段原创任务链，涵盖对话条件/效果、跨区调查、奖励和知识图谱关系。事件、人物日程、任务目标、对白分支、奖励、地图地标与图谱引用通过 Schema 和资源闭合校验。
5. 仅使用已登记且随发行包提供的本地 CC0 图素和许可；浏览器运行不依赖远程素材，角色沿用 Puny Characters CC0 图集。
6. 专项验证覆盖旧图层哈希/区域锚点、6 个方向关口端点与地图 BFS、三段世界路线、任务状态流、合法水路叠层、发行素材引用、标签布局及生成器幂等。浏览器核对全景、拖动、缩放、键盘平移、选点和 Home；根页面不能随滚轮离开舆图视口。
7. 按现有资料生成器顺序重跑 Round 96 和必要旧生成器后，本轮数据可重建；专项烟测、资料/MOD 审计、全量 `npm run check`、`npm run build` 和 `git diff --check` 通过，日志写明结果。更新 `CHANGELOG.md`、`DEVLOG.md`、`ROADMAP.md` 及地图、人物、任务、图谱相关文档，提交一个 `round-96: ...` commit。

## 子任务

1. 复核雾航湾和归帆洲附近舆图、碰撞与过渡点；用现存 R95/更早基线保存 57 层哈希和 18 个旧区域锚点。
2. 在中南海域确定岛屿形状、区域中心、地标和航路，验证不覆盖旧地貌，并注明与水面装饰的刻意叠层。
3. 实现可重复运行的 Round 96 生成器，创建两张分层百格岛图、世界岛屿/航路层、两个区域及三组往返关口。
4. 增加 NPC 七时段日程、原创对话和跨区连续任务，接入区域事件、既有奖励、发现状态与图谱。
5. 编写专项验证，检查两图入口/出生点/人物/调查点/返回路的 BFS、完整世界路线、旧图层与锚点、数据闭合、素材许可、标签及生成器幂等。
6. 依既定顺序重跑历史生成器，确保本轮新增层、区域和任务可恢复；运行自动化与浏览器操作，记录没能手动走完的范围。
7. 更新路线图册、角色、任务、图谱、开发日志和变更记录，核查提交内容并创建 Round 96 commit。

## 风险

- Claude Code 侦察中的总关口增量建议与三组往返路线不符：三组双向路线应新增 6 个有向关口，最终计数需实算并同步审计/文档，不照搬错误计数。
- 雾航湾有既存地貌水纹；新航线覆盖它须明确为航道叠层，不能覆盖旧像素数据或把旧海岸误画成陆地。
- 千里石塘与归帆洲接近，岛屿间距和落岸端点需按实际已有沙岸像素设计，避免海路看似断裂或踩进碰撞格。
- 中南区域现有标签较少，但全景标记需实测；位置调整不得漂移旧区域。
- 新任务依赖跨图移动和 NPC 日程；测试须按真实解释器验证阶段信号与提交条件，不只检查静态 JSON。
