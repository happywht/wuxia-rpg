# Round 97 计划：东溟中部航路与澜心洲

## 本轮目标

利用东溟中部已测得的大片空海，建设两处真正可探索的中继区域，形成风回岛—澜心洲—引航礁—天门关的东向航路，并为潮生屿接入澜心洲的替代海路。新区域补全大型可移动舆图中的东中部空带，避免仅增加装饰层或不连通的地标。

Round 97 开始时舆图为 768×576 格、8 源像素/格、61 层 RLE；有 20 个区域、42 个有向关口、72 个地标和 64 个固定事件。按现有关口图计算，天门关到潮生屿最短路径为 5 段。选址前解码舆图并逐格检查候选岛形：澜心洲中心 `(480,190)`、引航礁中心 `(520,110)` 的候选椭圆范围目前没有命中旧非海水图层；路线上仍须执行完整叠层和关口可达性验证。新位置分别靠近潮生屿/风回岛和雁回崖/天门关，填充东西相隔区域之间的空海。

仅复用仓库已登记、随包提供的 CC0 Puny World 与 Puny Characters 素材，不添加未经核验的新资源或运行时远程素材。

## 用户故事

- 玩家能从风回岛或潮生屿登上澜心洲，经引航礁抵达天门关；各地图之间的出口可从实际可走格到达。
- 玩家能在两处新区域探索不同的海岸/礁岛地貌，调查航标与潮流线索，和按时段活动的人物交谈并完成连续差事。
- 查看 768×576 可移动舆图的玩家能看到东溟中部新增岛屿与海路；既有舆图图层、已发布区域锚点、拖动/缩放/键盘平移/Home 复位回归不回退。
- 内容维护者能重复运行 Round 97 生成器，并在重建 Round 96→97 后得到一致数据。

## 验收标准

1. 本计划先于实现；至少六个可验证子任务，包含世界资料、两张地图、任务/人物、自动化验证、文档和提交。
2. 舆图维持 768×576 与 8 源像素/格；Round 96 的 61 层逐格哈希和 20 个区域中心不变。两处新岛只落在许可的海洋背景；任何其他旧图层重叠须显式说明并由专项测试约束。新增海路不可遮盖旧陆地、植被或道路，也不得穿过本轮新岛陆地；每段航线的绘制端点须紧邻对应岸线，不能浮在岛内或离岸断开。
3. 新增两张完整 100×100 可探索地图，绘制层与碰撞分离。风回岛、潮生屿、两处新区域、天门关间的 4 组双向关口（共 8 个有向关口）端点均可达；无入口碰撞、歧义触发或死路。新路线使天门关至潮生屿最短路径由 5 段减至 3 段。
4. 至少两名新 NPC 有七时段日程；新增两段有前置关系的原创任务，涵盖跨区域调查、对白条件/效果、奖励和图谱关系。任务、对白、事件、人物日程、图谱引用通过 Schema 与资源闭合检查。
5. 地标、事件和海路引导玩家读懂岛屿之间的方向；新增区域名称在常用缩放级别保持可辨认，不遮挡旧区域标记。
6. 资源仅引用已登记并纳入发行清单的 CC0 本地素材；不新增来源素材、不请求远程资源。
7. 专项测试覆盖旧图层/锚点基线、生成器幂等、许可海水叠层、两图出生点至出口/NPC/调查点的 BFS、8 个新关口端点、三段世界路线、任务状态流及标签布局。按数据生成器依赖顺序重建 R96 与 R97 后仍通过。
8. 运行 `npm run smoke:round-97`、`npm run check`、`npm run build` 与 `git diff --check`；如环境允许，再通过本地页面核对全景、拖动、缩放、选点与新路线可见性。命令和结果写入开发日志。
9. 更新 `CHANGELOG.md`、`DEVLOG.md`、`ROADMAP.md` 和地图、任务、人物、图谱相关文档；创建且只创建一个 `round-97: ...` 迭代提交。

## 子任务

1. 以 Round 96 已提交数据为基线，冻结 61 层哈希、20 个旧区域中心，逐格复核 `(480,190)`、`(520,110)` 周围完整岛形、路由走廊及区域标签间距。
2. 设计并实现可重复运行的生成器，新增两张 100×100 分层地图、四层总图地貌/海路、两个区域及四组双向关口；所有出入口先用实际地图碰撞做 BFS 选点。
3. 增加两名七时段 NPC、跨两岛的顺序差事与奖励，绑定区域事件/地标并补充知识图谱关系。
4. 编写专项验证与烟测，校验图层叠层、旧基线、地图端点、最短路、任务解释器状态推进、素材引用、标签布局和两遍生成幂等。
5. 依赖顺序重放 R96/R97 生成器，执行专项与全量检查/构建；对失败项定位并修复，不降低既有断言。
6. 更新地图/人物/任务/图谱说明、参考素材记录、变更记录、开发日志和路线图，审阅暂存清单后提交。

## 风险

- 新锚点靠近旧区域投影，须核验地图标记和标签，不以几何空白代替实际可读性测试。
- 海岸处旧地图边缘常被碰撞格围住；新关口候选必须落在可到达的非阻挡格上，避免只验证静态坐标。
- 航线胶囊若延伸到新岛陆地，会呈现穿岛的水路；叠层审计除对比所有旧图层外，还需与本轮岛陆遮罩逐格相交并核对岸线距离。
- 引航礁靠近天门关海岸，海路端点应停在旧陆地之外并连到现有岸线，不覆盖雪岭道路或植被。
- 四组新增路线拓扑可能让既有两区出现多条路线；导航选择、单段入口与任务进度必须验证无歧义。
- 浏览器手动验证可能受本机自动化安全层限制；若未执行，应在日志中明确说明，不能以自动化测试代称手动验证。
