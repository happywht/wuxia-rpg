# Round 98：统一设定与江南—渡口旅程入口

## 目标与用户故事
作为初到江南的抄书学徒，我能理解残篇目前可核实的线索，知道为什么去渡口、向谁问路；旧档即使已经交出残篇，也能继续调查。
当前王朝统一为大雍；北界碑中的大梁是旧朝遗刻，地理说明明确区分历史与当下。

## 验收标准
- 不新增地图，不修改地图通行、坐标、资源 ID 或存档协议。
- 沈墨涵不再许诺不存在的子时会面；至少提供一条当场可执行的调查入口。
- 货郎口信、渡籍补录的未接/进行/完成状态提供对应提示，给出渡口人物与出镇方向；残篇不存在时仍可推进。
- 残篇只提供阶段性事实，不冒称已破解武学或已查明幕后刀客；重复查看不能刷物品、声望或关系。
- 大梁相关生成器和生成资料一致；新增测试覆盖状态提示、无残篇入口、重复效果及设定一致性。
- 数据、类型、完整测试、文档审计与构建通过；真实键盘旅程留待 Round 99，不能由自动测试代替。

## 可验证子任务
1. 统一旧朝/当朝文本，修正源生成器与 JSON，记录事实与未解悬念。
2. 深化书铺、货郎、渡口/书院对白及既有两项差事，接通现有旅程，避免奖励漏洞。
3. 增加回归测试，执行检查，更新目标进度和迭代文档并提交。

## 风险与约束
旧存档可能已交残篇，不能用持有残篇做唯一前置。对话系统没有任意布尔变量，采用既有任务状态和幂等见闻，不伪造阶段规则。生成器可能覆盖手改资料，须复核源与输出。既有奖励问题仅修复本轮涉及入口，其他问题明确记录。
